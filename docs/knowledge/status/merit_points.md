# メリットポイントの割り振り上限

メリットポイントには **項目ごとの上限** と、カテゴリによっては **グループ合計の上限**
の 2 段の制約がある。UI の入力クランプはこの表に従う
(`web/src/constants.ts` の `MERIT_*` / `JOB_MERIT_*`、[ADR 0021](../../adr/0021-character-edit-density-and-sections.md))。

## 上限一覧

| カテゴリ | 項目 | 項目ごとの上限 | グループ合計の上限 |
| --- | --- | --- | --- |
| 基礎ステータス | HP / MP / STR / DEX / VIT / AGI / INT / MND / CHR | 15 | なし |
| スキル | 戦闘 19 種 + 魔法 14 種 | 8 | なし |
| その他 | 敵対心+ / 敵対心- / クリティカルヒット率 / 被クリティカルヒット率 / 詠唱中断率 | 5 | **10** |
| ジョブ別メリット | ジョブごとにグループ 1 / グループ 2 | 5 | **各グループ 10** |

「その他」とジョブ別メリットは、項目ごとに 5 まで振れても
グループ合計が上限に達したらそれ以上は振れない。
たとえば「その他」で敵対心+ に 5、クリティカルヒット率に 3 を振ると、
残りの 3 項目に振れるのは合計 2 まで。

## スキルメリットの効果

スキルメリット 1 ランクにつき、そのスキルの**上限が +2** される
(`rust/src/skills.rs` の `SkillKind::merit_bonus` — `rank * 2`)。
ランク 8 まで振れば +16。
上限が 0 のスキル (Lv1 以上のジョブに該当スキルのランクが無い場合) には加算されない。

## 総獲得量について

FFXI 本体には「所持しているメリットポイントの総量」という概念があり、
上限解放クエストでしか増えない共有プールとして全カテゴリの割り振りを縛る。
**このシミュレータではこれをモデル化していない** ―― 各項目・各グループの上限だけを見る。
そのため UI が出す「計 N / M pt」の M は、
基礎とスキルについては「全欄を上限まで振ったときの理論値」(基礎 9×15=135 / スキル 33×8=264)
であり、実際に到達できるとは限らない。

## ステータス計算への反映

基礎ステータスのメリットは `rust/src/status.rs` の `MeritPoints` として
ステータス合計に加算される (詳細は [base_stats.md](base_stats.md) の
「メリットポイント補正」)。
「その他」のメリットは敵対心・クリティカル率などの個別計算で参照する。
