# 日本語説明文の条件ラベル

アイテムの日本語の説明文に出る、コロン付きのラベル（条件ラベル）の意味と適用範囲を記録する。条件ラベルは、その後に続く効果が誰に乗るか、いつ乗るかを示す。

```
防21 ペット:命中+3 モクシャ+3
```

この例の `命中+3` と `モクシャ+3` はどちらもペットの効果で、装備者には乗らない。

## 適用範囲はソースによって変わる

ラベルの効力はラベルより後ろに及ぶ。ラベルより前は、装備者に常に乗る効果である [1]。

```
防5 CHR+5 ヘイスト+5% ペット:ヘイスト+5%
→ 装備者: 防5 / CHR+5 / ヘイスト+5%、ペット: ヘイスト+5%
```

効力がどこで切れるかは、そのテキストの改行が何を意味するかで決まる。装備の解釈に使う 3 つのテキスト（[ADR 0019](../../adr/0019-japanese-as-single-interpretation-source.md)）のうち、アイテム説明文だけが他の 2 つと規則が違う。

| テキスト | 改行の意味 | ラベルの適用範囲 |
| --- | --- | --- |
| アイテムデータの `description_ja` | ゲーム内の表示の折り返し | 次のラベルか、テキストの末尾まで |
| `augments.json` のオーグメント文 | 効果 1 件ごとの区切り | 行末まで |
| カスタム説明（ユーザーが入力する） | ユーザーが行ごとに書く | 行末まで |

### アイテム説明文: 折り返した行もラベルの配下

ゲーム内の説明文は 1 続きのテキストで、改行は表示の折り返しにすぎない。そのためラベルの効力は続きの行にも及ぶ [1]。

```
防1 サンドリア王国軍支配エリア:
インビジ効果アップ スニーク効果アップ    ← 支配エリアの中でだけ効く (近衛騎士リバリ)
移動速度+12%                             ← 同上
```

```
防139 ... ヘイスト+6%
オートマトン:MP+110 ケアル回復量+16%
ヘイスト+5% 被ダメージ-6%                ← オートマトンの効果 (ＦＯチュリダル+4)
コンビネーション:命中+ 飛命+ 魔命+       ← ここでラベルが切り替わる
```

2026-08 時点のアイテムデータで、ラベルの行の後に続きの行があるアイテムは 383 件ある。383 件すべてで続きの行はラベルの配下で、配下に `防n`・`Ｄn`・`隔n` のような装備者だけの表記が来る反例は 0 件だった [1]。

`description_ja` の改行は、リテラルの `\n`（バックスラッシュと n）で入っている [1]。

### オーグメント文: 行末まで

`augments.json` の改行は wiki の `<br>` から来ており、効果 1 件ごとの区切りとして入っている（`scripts/scrape_augments.py`）。折り返しではないので、続きの行は装備者の効果である [2]。

```
ペット:攻+15
攻+5                    ← 装備者の効果 (ネオアニメーター 21430)
```

```
命中+30 魔命+30
ペット:命中+30 魔命+30
ストアTP+7              ← 装備者の効果 (ジャストクラウン 24165 Rank30)
トリプルアタック+4%     ← 同上
```

## コロンは半角と全角の両方がある

ほとんどのラベルは半角の `:` だが、慈悲 / 慈愛 / 寵愛装束（id 24180〜24194）の Rank30 のオーグメントだけが、全角の `ペット：` で書かれている。上流の wiki の表記揺れである [2]。

## ラベルの種類

2026-08 時点のアイテムデータで、コロン付きのラベルは 227 種類あり、そのうち配下に数値を含むものは 170 種類である。出現数の多い順に並べる [1]。

| ラベル | 件数 | 種別 |
| --- | --- | --- |
| コンビネーション | 1301 | 条件（セット装備の数） |
| 追加効果 | 546 | 条件（発動したとき） |
| エンチャント | 423 | 条件（発動したとき） |
| 潜在能力 | 383 | 条件 |
| アフターマス | 341 | 条件（ウェポンスキルの後） |
| ペット / 召喚獣 / オートマトン / 飛竜 / 呼び出しペット | 計 816 | 効果を受けるのがペット |
| ユニティランク | 217 | 条件（ユニティの順位） |
| 右耳 | 68 | 条件（装備スロット） |
| デュナミス〔Ｄ〕/ レイヴ / ビシージ / カンパニエ など | — | 条件（エリア・コンテンツ） |
| 曜日 / 天候 / 日中 / 夜間 / 満月 など | — | 条件（時間・天候） |
| 対ヴァーミン / 対プラントイド など | — | 条件（敵の種族） |
| メインウェポン / 素手 / 侍 / ナ など | — | 条件（装備・ジョブ） |

数値を伴うラベルはどれも、効果を受けるのが装備者以外か、常に発動するのではない条件かのどちらかである。装備者に常に乗るステータスをコロン付きで書く表記は無い。装備者に常に乗るステータスは `防21`・`命中+9` のようにコロン無しで書かれる [1]。

英語の説明文は `DMG:+165 Delay:+240` のようにステータス自体をコロンで書くので、同じ規則をそのまま当てはめられない。英語の説明文にも折り返しがあり、ラベルの配下が複数行に分かれる点は日本語と同じである [1]。

## 日本語の説明文を持たないアイテム

`description_ja` が空のアイテムの件数は次のとおり [3]。

| 区分 | 件数 |
| --- | --- |
| 全アイテム | 15,527 |
| `description_ja` が空 | 52（Armor 47・Weapon 5） |
| そのうち `description_en` が空でない | 0 |

例: Moonshade Earring（胡蝶のイヤリング、id 11697）、Fighter's Torque（ファイタートルク、id 11988）。

日本語の説明文が無いアイテムは、英語の説明文も持たない。

## ff11sim での扱い

- `コンビネーション:` はセット装備の数で発動するので厳密には条件付きだが、ff11sim は条件ラベルとして扱わず、配下の値を常に乗るものとして読む。装備セットを組むためのツールで、セット効果は実際に発動していることが多いためである（[ADR 0019](../../adr/0019-japanese-as-single-interpretation-source.md)）。`コンビネーション(召喚獣のみ):` のような、効果を受ける者を限った変種はこの例外にしない。`コンビネーション:` は常に乗るものとして読むが、直前のラベルの区切りにはなる。
- 全角の `：` は、こちらで直すと再スクレイプで戻るので、読む側で半角と全角の両方を受ける。
- 条件ラベルの処理の窓口は `rust/src/equip_stats.rs` である。`strip_conditional_labels` が条件ラベルとその配下を落とし、適用範囲（`LabelScopeMode` の `Wrapped` = 次のラベルか末尾まで、`PerLine` = 行末まで）は `rust/src/equip.rs` の `Equip::texts_ja` がテキストごとに上の表の値を渡す。ステータスの計算とユーザー定義プロパティはどちらもここを通るので、規則が揃う。ラベル自身も落とすのは、残すと後の正規化で `ペット:` が `Pet:` になり、英語向けのセグメントの除去が次のコロンまで食う既知の癖（[tech-debt/equip-stats-js-quirks.md](../../tech-debt/equip-stats-js-quirks.md) の 1 番）を起こすためである。
- 検索の説明文ステータスソートは `extract_stat_from_description` で同じ規則を使い、ラベルの配下を読み飛ばす（生のテキストを渡すのはアイテム説明文だけなので `Wrapped` に固定）。こちらはラベル自身を範囲に含めないので、`DEF:77` から `DEF` を引く使い方や、`ペット:命中` のようにラベルを込めた指定が残る。
- ラベルの判定条件は「非 ASCII 文字を含むこと」である。説明文ステータスソートの今の実装は、`description_ja` が無いアイテムで `description_en` を代わりに使うので、英語の `DMG:+165` のような表記を条件ラベルと誤認しないようにしている。仕様書では英語での代替をやめると決めた（[0004](../../specs/0004-equip-interpretation.md) の AC2、[0005](../../specs/0005-item-search.md) の AC30）。日本語の説明文が無いアイテムは英語の説明文も持たないので、代替をやめても並び順と値は変わらない。
- 英語の説明文の除去は「次のコロンまで」で行数を見ておらず、日本語と挙動が違う（[tech-debt/equip-stats-js-quirks.md](../../tech-debt/equip-stats-js-quirks.md) の 1 番）。英語の経路は参照実装としてしか使わないので、そのままにしてある。

## 未確認の事項

- 件数はどれもアイテムデータを数えた結果で、ゲーム内の表示とは照合していない。2026-08 の集計 [1] は、数えたアイテムデータの版を記録していない。
- 折り返した行がラベルの配下であることは、アイテムデータの反例が 0 件であることから推論したもので、ゲーム内の効果では確かめていない。
