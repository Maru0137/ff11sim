# 魔法命中（魔命）

魔法命中は、[二次ステータス](secondary_status.md)の 1 つで、魔法の命中率を求めるときに使う値である。ゲームでは「魔命」と呼ぶ。「魔法命中率」「魔法命中」の表記も混ざる [1]。

_インスタンス元_: 二次ステータス
_排他_: 物理命中

## 効果

魔法命中は、魔法の命中率（魔法が当たる確率）を決める値の 1 つである。魔法の命中率は、攻撃する側の魔命の要素の合計と、防御する側の魔回避の要素の合計の差で決まる。上限は 95%、下限は 5% である [1]。

魔法の命中率に入る要素のうち、次のものは使う魔法と相手で決まるので、この文書の魔法命中には含めず、魔法の命中率の側の要素とする。

- INT 差・MND 差など、自分と相手の能力値の差。白魔法は MND 差、黒魔法は INT 差、呪歌は CHR 差を参照するのが一般的で、魔法ごとに違う [1]。
- 魔法ごとに決まった補正（例: スタン・フラッシュは +200）[1]。

属性ウェポンスキルは外れないが、魔法のレジストを受ける [2]。そのため属性ウェポンスキルの魔法命中は、命中するかではなく、レジストのされやすさに効く。

装備で魔法命中を上げるのは「魔命+」である（[二次ステータス](secondary_status.md) の一覧）。

## 計算式

### 魔法命中

```
魔法命中 = 魔命ボーナス + 行動のスキル + メインの武器の魔命スキル
```

| 項 | 内容 |
|---|---|
| 魔命ボーナス | 装備の「魔命+」・ジョブ特性・ギフト・ジョブポイントの合計（「魔命ボーナス」節） |
| 行動のスキル | 魔法ならその魔法のスキル、ウェポンスキルならその武器の武器のスキル値（「行動のスキル」節）。スキル 1 が魔命 1 に当たる [1] |
| メインの武器の魔命スキル | メインスロットに着けたアイテムレベル装備の武器が持つ「魔命スキル+」。魔命スキル 1 が魔命 1 に当たる。ほかのスロットの魔命スキルは効かない [1][3] |

### 行動のスキル

| 行動 | 行動のスキル |
|---|---|
| 魔法 | その魔法のスキルの有効スキル値（[スキル](skill.md)） |
| ウェポンスキル（メインの武器） | メインの武器の武器のスキル値 [4] |
| ウェポンスキル（遠隔攻撃の武器） | レンジスロットの武器の武器のスキル値 [4] |

武器のスキル値の求め方は [物理攻撃力](physical_attack.md) の「武器のスキル値」にある。

### 魔法の種類ごとの例外

呪歌と風水魔法は、魔法のスキルに加えて楽器のスキルを足す。

```
呪歌の行動のスキル     = 歌唱スキル + 管楽器スキル（レンジスロットに管楽器を着けているときだけ）
風水魔法の行動のスキル = 風水魔法スキル + 風水鈴スキル（レンジスロットに風水鈴を着けているときだけ）
```

呪歌では、レンジスロットに弦楽器を着けていても、弦楽器スキルは足さない。

### 魔命ボーナス

```
魔命ボーナス = 装備の魔命+ + ジョブ特性 + ギフト「魔法命中アップ」 + ジョブポイントのカテゴリの魔命
```

#### ジョブ特性

ジョブ特性「魔法命中率アップ」は、青魔道士が青魔法のセットで得る追加特性である。ランク 1 は +10、ランク 2 は累積 +22 で、どちらも最短でレベル 99 で得る [5]。

ほかに、条件付きで魔命を上げるジョブ特性がある。タンデムヒット（ペットと同じ対象を攻撃しているとき）、カーディナルチャント（対象が南にいるとき）など [1]。

#### ギフト「魔法命中アップ」

メインジョブの累計ジョブポイントに応じて段階が解放され、解放した段階の値の総和を足す。戦士の値は次のとおり [6]。

| 段階 | 解放する累計ジョブポイント | 値 | 総和 |
|---|---|---|---|
| 1 | 60 | +5 | +5 |
| 2 | 360 | +8 | +13 |
| 3 | 910 | +10 | +23 |
| 4 | 1710 | +13 | +36 |

#### ジョブポイントのカテゴリの魔命

一部のジョブのジョブポイントのカテゴリには、ペット・呪歌・忍術・召喚獣・物理系青魔法の追加効果の魔命+ がある（各 1 × 20 段階）[1]。

## 計算例

精霊魔法スキルの有効スキル値が 450、装備の魔命+ の合計が 200、メインの武器の魔命スキルが 250 の戦士が、ギフトをすべて解放して精霊魔法を使うとき（ジョブ特性は無い）:

```
魔命ボーナス = 200 + 0 + 36 + 0 = 236
魔法命中     = 236 + 450 + 250 = 936
```

## 歴史

- **2013 年 10 月 8 日のバージョンアップ**: アイテムレベル装備の武器の魔命+ は、メインスロットに着けたときだけ効くようになった [1]。
- **2013 年 11 月 5 日のバージョンアップ**: アイテムレベル装備の武器の魔命+ は「魔命スキル+」と表示されるようになった [1]。

## 未確認の事項

- [1][2][3][5][6] は WebFetch で要約して読んだもので、原文を目で確かめていない。
- [1] は、ギフト「魔法命中アップ」の 1 段階目を「ジョブ全般で +10、白魔道士・黒魔道士・赤魔道士などで +5〜+7」と書いているが、[6] の戦士の 1 段階目は +5 で食い違う。
- 「魔法の種類ごとの例外」（呪歌の管楽器スキル、風水魔法の風水鈴スキル）の出典は無い。書き直す前のこの文書から引き継いだ。
- ウェポンスキルの行動のスキル [4] は、ユーザーの確認による。ゲームの一次情報では確かめられなかった。[2] は、属性ウェポンスキルに物理のウェポンスキルと同じような魔命のボーナスがあると推定しているが、確定していない。
- 計算例はこの文書の式に当てはめた値で、ゲーム内の表示とは照合していない。
