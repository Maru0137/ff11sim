# 装備スロットの名称

キャラクターが装備品を着ける枠（スロット）は 16 個ある。このファイルは、ゲームでの各スロットの名称と、
ff11sim の画面に出す表示名（[data/equipment_slots.json](../../../../data/equipment_slots.json) の `label_ja`）の対応を記録する。

## 名称の対応

「名称」と英語名は [装備/FF11用語辞典](https://wiki.ffo.jp/html/140.html) の表記に従う。

| 名称 | 英語名 | ff11sim の表示名 | `key` |
|---|---|---|---|
| メインウェポン | Main | メイン | `main` |
| サブウェポン | Sub | サブ | `sub` |
| レンジウェポン | Range | レンジ | `range` |
| 矢弾 | Ammo | 矢弾 | `ammo` |
| 頭 | Head | 頭 | `head` |
| 首 | Neck | 首 | `neck` |
| 左耳 | Ear1 / L.ear | 左耳 | `ear1` |
| 右耳 | Ear2 / R.ear | 右耳 | `ear2` |
| 胴 | Body | 胴 | `body` |
| 両手 | Hands | 両手 | `hands` |
| 左手の指 | Ring1 / L.ring | 左指 | `ring1` |
| 右手の指 | Ring2 / R.ring | 右指 | `ring2` |
| 背 | Back | 背 | `back` |
| 腰 | Waist | 腰 | `waist` |
| 両脚 | Legs | 両脚 | `legs` |
| 両足 | Feet | 両足 | `feet` |

名称と表示名が異なるのは、メインウェポン・サブウェポン・レンジウェポン・左手の指・右手の指の 5 つである。
ほかの 11 個は名称をそのまま表示名にしている。

## 武器スロットと矢弾の関係

- レンジウェポンには、弓・射撃の発射台・ブーメランなどの非消費型の投てき武器・楽器・釣り竿を着ける。
- 矢弾には、矢・ボルト・弾・消費型の投てき武器（手裏剣など）・釣り餌を着ける。
- 矢・ボルト・弾・釣り餌はレンジウェポンと併用する設計で、消費型の投てき武器は、レンジウェポンに非消費型の投てき武器を着けているときは使えない。

出典: [レンジウェポン/FF11用語辞典](https://wiki.ffo.jp/html/2857.html)、[装備/FF11用語辞典](https://wiki.ffo.jp/html/140.html)

- レンジウェポンに武器を着けているとき、矢弾に投てき武器（手裏剣など）は着けられない。非消費型の投てき武器だけでなく、弓・銃を着けているときも同じである。
- したがって、矢弾に投てき武器を着けているとき、レンジウェポンはいつも空で、その投てき武器が遠隔攻撃に使う武器になる。

出典: ユーザーの確認（2026-10-25）。ユーザーの言葉は「レンジスロットに投てき武器を装備しているとき、矢弾に投てき武器を同時に装備することはできない」「レンジスロットに弓や銃（投てき以外の遠隔武器）を着けたまま、矢弾スロットに手裏剣（投てき武器）を着けることはできない」。
仕様書での扱いは [0003 の用語「遠隔攻撃に使う武器」](../../specs/0003-status-view-management.md) と [0007](../../specs/0007-status-calculation.md) の「スロット専用のスキルボーナス」。

## 確度

- 出典は有志が運営する用語辞典で、スクウェア・エニックスの公式資料ではない。ゲーム内の装備画面での表記とは照合していない。
- 指の名称は用語辞典の「左手の指」「右手の指」を採った。ゲーム内の表記が同じかは確かめていない。
- 矢弾の投てき武器とレンジウェポンを併用できない規則は、ユーザーが投てき武器・弓・銃の例で確かめたもので、ゲーム内では照合していない。レンジウェポンに楽器・風水鈴・釣り竿を着けているときに矢弾に投てき武器を着けられるかは、ひとつずつは確かめていない（仕様書 0003 の D4）。
