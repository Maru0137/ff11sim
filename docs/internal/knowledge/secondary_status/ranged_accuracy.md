# 遠隔物理命中（飛命）

遠隔物理命中は、[物理命中](physical_accuracy.md)の 1 つで、投てき・射撃・弓術の武器による遠隔攻撃の命中率に影響する値である。ゲームでは「飛命」と呼ぶ [1]。

_インスタンス元_: 物理命中
_排他_: 近接物理命中

## 効果

遠隔物理命中は、遠隔攻撃の命中率（攻撃が当たる確率）に影響する値の 1 つである。遠隔物理命中を上げても命中率が直接上がるのではなく、命中率に影響する値の 1 つが上がる [1]。

装備の「命中+」と「攻+」は、遠隔攻撃には影響しない [1]。装備で遠隔物理命中を上げるのは「飛命+」である。
ジョブ特性「物理命中率アップ」とギフト「物理命中アップ」は、近接物理命中と遠隔物理命中の両方に効く（[物理命中](physical_accuracy.md) の「共通の規則」）。

## 計算式

### 遠隔物理命中

```
遠隔物理命中 = int(AGI × 0.75) + 武器スキルの項 + 装備の飛命 + 物理命中ボーナス + 遠隔物理命中ボーナス
```

`int()` は小数点以下の切り捨て。遠隔物理命中の下限は 1 である [1]。

| 項 | 内容 |
|---|---|
| AGI | キャラクターの AGI（[基本ステータス](../base_status/base_stats.md)）。1 上がるごとに遠隔物理命中が 0.75 上がる [1] |
| 武器スキルの項 | 遠隔攻撃に使う武器の武器のスキル値から求める（「武器スキルの項」節） |
| 装備の飛命 | 装備の「飛命+」の合計 |
| 物理命中ボーナス | ジョブ特性・ギフト・ジョブポイントのカテゴリによるボーナス。近接物理命中と共通（[物理命中](physical_accuracy.md) の「共通の規則」） |
| 遠隔物理命中ボーナス | 遠隔物理命中にだけ足すボーナス（「遠隔物理命中ボーナス」節） |

### 武器スキルの項

近接物理命中の武器スキルの項（[近接物理命中](melee_accuracy.md)）は 200・400・600 で上がり方が変わるが、遠隔物理命中は 200 でだけ変わる [1]。

| 武器のスキル値 | 武器スキルの項 |
|---|---|
| 0 以下 | 0 |
| 1〜200 | スキル値そのまま |
| 201 以上 | 200 + int((skill − 200) × 0.9) |

近接物理命中と遠隔物理命中の武器スキルの項の比較:

| skill | 近接 | 遠隔 |
|---|---|---|
| 300 | 290 | 290 |
| 400 | 380 | 380 |
| 500 | 460 | 470 |
| 600 | 540 | 560 |
| 700 | 630 | 650 |
| 733 | 659 | 679 |
| 800 | 720 | 740 |

### 遠隔物理命中ボーナス

```
遠隔物理命中ボーナス = ギフトの飛命 + ジョブポイントのカテゴリの飛命
```

コルセアのジョブポイントのカテゴリ「遠隔命中アップ」は、1 ランクにつき遠隔物理命中を +1 する。最大ランク 20 で +20 になる [2]。

## 計算例

ヒューム コルセア99 / 侍59、マスターレベル50、遠隔WS 装備セット:

- AGI（装備込み）= 378
- 射撃の武器のスキル値 = 733（スキル上限 448 + メリットポイント 16 + 装備 269）
- 武器スキルの項 = 200 + int((733 − 200) × 0.9) = 200 + 479 = 679
- 装備の飛命 = 460
- 物理命中ボーナス = 0（ジョブ特性）+ 36（ギフトの 4 番目の枠）+ 0（ジョブポイントのカテゴリ）= 36
- 遠隔物理命中ボーナス = 0（ギフト）+ 20（ジョブポイントのカテゴリ「遠隔命中アップ」ランク 20）= 20

```
遠隔物理命中 = int(378 × 0.75) + 679 + 460 + 36 + 20
            = 283 + 679 + 460 + 36 + 20
            = 1478
```

## 未確認の事項

- [1] は WebFetch で要約して読んだもので、原文を目で確かめていない。
- [1] の「命中+ は遠隔攻撃に影響しない」は、ギフト「物理命中アップ」が「物理・遠隔命中」に効くこと（[物理命中](physical_accuracy.md) の出典）から、装備の「命中+」を指すと読んだ。[1] が装備だけを指すと明記しているかは確かめていない。
- 武器スキルの項の 0 以下の区分と、近接との比較の表の値は、この文書の式から求めたもの。
- 計算例の入力は ff11sim で組んだ装備セットの値で、ゲーム内の表示とは照合していない。
