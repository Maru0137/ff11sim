# スキル

スキルは、キャラクターの持つさまざまな技能を数値で表したものである [1]。

_種別_: kind
_分割_: 戦闘スキル、魔法スキル、合成スキル、羽術スキル

この文書では、次の 4 つの語を使う。

| 語 | 定義 |
|---|---|
| スキル値 | キャラクターがそのスキルについて持っている値。使うことで上がる |
| スキルキャップ | ジョブとレベルで決まる、スキル値の上限（「上限」節） |
| 有効スキル値 | スキル値をスキルキャップで抑え、メリットポイント・装備・ギフトのボーナスを足した、今効いている値。[二次ステータス](secondary_status.md)の 1 つ（「計算式」節） |
| 武器のスキル値 | 武器のスキルの有効スキル値に、その武器を着けたスロットのスロット専用のスキルボーナスを足した値（[物理攻撃力](physical_attack.md) の「武器のスキル値」） |

## 効果

スキルは次の種類に分かれる [1]。

| 種類 | 内容 [1] | 効く先（有効スキル値が式の項になる二次ステータス） |
|---|---|---|
| 戦闘スキル | 物理攻撃に関わるスキル。格闘・片手剣などの武器スキルと、回避・盾などの防御系のスキル | 武器スキル: [近接物理攻撃力](melee_attack.md)・[遠隔物理攻撃力](ranged_attack.md)・[近接物理命中](melee_accuracy.md)・[遠隔物理命中](ranged_accuracy.md)。回避スキル: [物理回避](physical_evasion.md) |
| 魔法スキル | 魔法に関わるスキル [4]。精霊・回復・弱体・強化などの魔法のスキルのほか、歌唱・楽器・忍術のスキルを含む | [魔法命中](magic_accuracy.md) |
| 合成スキル | クリスタルを使う合成・釣り・錬成に関わるスキル | 二次ステータスには効かない |
| 羽術スキル | チョコボの穴掘りに関わるスキル | 二次ステータスには効かない |

## 計算式

### 有効スキル値

```
有効スキル値 = min(スキル値, スキル上限)
            + スキルのメリットポイントのランク × 2
            + 全スロット共通のスキルボーナス
            + ギフトのスキルボーナス
```

スキル上限は、メインジョブとサポートジョブのスキルキャップから求める（「上限」節）。

- メリットポイントの分（ランク 1 につき +2、ランク 8 で +16）は、スキル上限で抑えた後に足す。そのため有効スキル値はスキル上限を超えうる [3]。
- スキル上限が 0 のスキルにも、メリットポイントの分・装備のスキルボーナス・ギフトのスキルボーナスは足す。0 になるのはスキル値の分だけである [3]。
- 武器のスキル値は、この 4 つの和に、足し先がそのスロットであるスロット専用のスキルボーナスを足したものである。矢弾スロットの投てき武器のスキルボーナスは、足し先がレンジスロットである [3]。

## 計算例

メインジョブのレベル 99・マスターレベル 0 で、そのスキルのランクが A+（スキルキャップ 424）、スキル値 424、スキルのメリットポイント 8 ランク、装備のスキルボーナス 0、ギフトのスキルボーナス 0 のとき:

```
有効スキル値 = min(424, 424) + 16 + 0 + 0 = 440
```

メインジョブが戦士・サポートジョブ無しで、歌唱スキル（戦士はランクを持たない）のメリットポイント 8 ランク、首の装備に歌唱スキル+10 があるとき、歌唱スキルの有効スキル値はスキル値によらず次のとおり:

```
有効スキル値 = 0 + 16 + 10 + 0 = 26
```

## 上限

### スキルキャップ

スキルキャップは、スキルがそのレベルで上限に達していること、またはその上限そのものである [2]。
ジョブごと・スキルごとに適性（スキルランク）が決まっていて、スキルキャップはスキルランクとレベルで決まる [2]。スキルランクは A+・A・B+・B・B-・C+・C・C-・D・E・F・G である [2]。

```
ジョブのスキルキャップ(job, skill, lv, master_lv)
  = そのジョブがスキルのランクを持たないとき 0
  = lv が 0 以下のとき 0
  = それ以外のとき ランクの式(rank, min(lv, 99)) + master_lv
```

2021 年 11 月 10 日のバージョンアップから、ジョブが本来持つスキルのスキルキャップは、マスターレベルの分だけ上がる [2]。

### スキル上限（メインジョブとサポートジョブの組）

有効スキル値に使うスキル上限は、メインジョブとサポートジョブのスキルキャップの大きい方である [3]。

```
スキル上限 = max(
  ジョブのスキルキャップ(メインジョブ, skill, メインジョブのレベル, マスターレベル),
  ジョブのスキルキャップ(サポートジョブ, skill, サポートジョブの有効レベル, 0)
)
```

- サポートジョブにはマスターレベルを足さない [3]。
- サポートジョブの有効レベルは、[基本ステータス](base_stats.md) の「サポートジョブ」節の上限で抑えたレベル。サポートジョブを選んでいないとき、または有効レベルが 0 のとき、サポートジョブの項は 0 である。
- メリットポイントはスキル上限を広げない [3]。
- メインジョブとサポートジョブのどちらもスキルを持たないとき、スキル上限は 0 である。

## 未確認の事項

- [1][2] は WebFetch で要約して読んだもので、原文を目で確かめていない。[2] の表は結合されたセルが崩れていたので、レベル帯ごとの式の表から読んだ。
- [2] はスキルランクを「11 段階」と書いているが、並んでいるランクは 12 個ある。[2] は G の名前を仮のものとしている。
- 小数を切り捨てることは、[2] の表の値から推論したもので、[2] に明記されていない。
- [2] の B+・B・B- の表は「71〜75」と「75〜80」でレベル 75 が重なっている。この文書は 75 を 71〜75 の帯に含め、76〜80 を次の帯とした。レベル 75 では、どちらの帯の式でも同じ値（B+ は 256）になる。
- スキル上限をメインジョブとサポートジョブのスキルキャップの大きい方とすること、サポートジョブにマスターレベルを足さないこと、メリットポイントの扱いは [3] で決めた扱いで、ゲームの一次情報では確かめていない。
- [1] は魔法スキルを「詠唱に関わるスキル」と書いているが、この文書は [4] に従い「魔法に関わるスキル」とした。
- 戦闘スキル・魔法スキルの細かい一覧（武器スキル 15 種、魔法スキル 14 種など）は書いていない。
- ジョブとスキルのランクの対応表は書いていない。
