# スキル上限と有効スキル値の計算仕様

スキル上限（あるスキルについて、今のメインジョブ・サポートジョブで効くキャラクターのスキル値の上限）と、
それを使った有効スキル値の求め方。語の定義は仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md)
の「用語」節にある。

> 2026-10-18 にユーザーの判断で改めた（ゲームの一次情報では未確認）。改める前は、スキルのメリットポイントが
> スキル上限を 1 ランクにつき 2 広げ、メインジョブとサポートジョブのどちらもスキルを持たない（上限 0 の）
> スキルには効かない、としていた。今の実装（`rust/src/skills.rs` の `effective_skill_parts`）は改める前の
> 規則のままで、直す対象である。

## ジョブ 1 つのスキル上限

```
ジョブのスキル上限(job, skill, lv, master_lv)
  = ランクが無い（そのジョブがスキルを持たない）とき 0
  = lv <= 0 のとき 0
  = 補間値(rank, min(lv, 99)) + max(master_lv, 0)
```

- ランク: `data/job_skill_ranks.json` のジョブ × スキルの値（`A+`〜`G`、`null` はスキルを持たない）
- 補間値: `data/skill_cap_control_points.json` の制御点（Lv 1・50・75・99）の値を線形補間し、四捨五入する

| ランク | Lv1 | Lv50 | Lv75 | Lv99 |
|---|---|---|---|---|
| A+ | 6 | 153 | 276 | 424 |
| A | 5 | 147 | 269 | 417 |
| B+ | 5 | 142 | 256 | 404 |
| B | 4 | 136 | 250 | 398 |
| B- | 4 | 126 | 240 | 388 |
| C+ | 4 | 116 | 230 | 378 |
| C | 4 | 101 | 225 | 373 |
| C- | 3 | 90 | 220 | 368 |
| D | 3 | 78 | 210 | 334 |
| E | 2 | 65 | 200 | 300 |
| F | 2 | 55 | 189 | 265 |
| G | 2 | 45 | 171 | 228 |

実装: `rust/src/skills.rs` の `skill_cap` と `job_skill_cap`。

## スキル上限（メインジョブとサポートジョブの組）

```
スキル上限 = max(
  ジョブのスキル上限(メインジョブ, skill, メインジョブのレベル, マスターレベル),
  ジョブのスキル上限(サポートジョブ, skill, サポートジョブの有効レベル, 0)
)
```

- サポートジョブにはマスターレベルを足さない。
- サポートジョブの有効レベルは [base_stats.md](base_stats.md) の「サポートジョブ」節の上限で抑えたレベル。
  サポートジョブを選んでいないとき、または有効レベルが 0 のとき、サポートジョブの項は 0 である。
- メリットポイントはスキル上限を広げない。
- メインジョブとサポートジョブのどちらもスキルを持たないとき、スキル上限は 0 である。

## 有効スキル値

```
有効スキル値 = min(キャラクターのスキル値, スキル上限)
            + スキルのメリットポイントのランク × 2
            + 全スロット共通のスキルボーナス
            + ギフトのスキルボーナス
```

- メリットポイントの分（1 ランクにつき +2、ランク 8 で +16）は、スキル上限で抑えた後に足す。したがって有効スキル値は
  スキル上限を超えうる。
- スキル上限が 0 のスキルでも、メリットポイントの分・装備のスキルボーナス・ギフトのスキルボーナスは足す
  （キャラクターのスキル値の分だけが 0 になる）。
- 武器のスキル値は、同じ 4 つの和に、足し先がそのスロットであるスロット専用のスキルボーナスを足したもの
  （仕様書 0007 の AC26。矢弾スロットの投てき武器のものは足し先がレンジスロット）。

### 例

メインジョブ Lv99・マスターレベル 0 で、そのスキルのランクが A+（上限 424）、キャラクターのスキル値 424、
スキルのメリットポイント 8 ランク、装備のスキルボーナス 0、ギフトのスキルボーナス 0 のとき、有効スキル値は
min(424, 424) + 16 = 440 である。

メインジョブ戦士・サポートジョブ無しで、歌唱スキル（戦士はランクを持たない）のメリットポイント 8 ランク、首の装備に
歌唱スキル+10 があるとき、歌唱スキルの有効スキル値はキャラクターのスキル値によらず 0 + 16 + 10 = 26 である。

## キャラクターの編集フォームでのスキル値の入力上限

キャラクターに記録するスキル値の入力上限（仕様書 [0002 キャラクターの管理](../../specs/0002-character-management.md)
の「スキル値の入力上限」）は、ジョブレベルが 1 以上の各ジョブについて「ジョブのスキル上限(そのジョブ, skill,
そのジョブのレベル, そのジョブのマスターレベル)」を求めた最大値である。メリットポイントは足さない。

実装: `rust/src/skills.rs` の `default_skill_value`（今はメリットポイントの分を足しており、直す対象）。

## 内訳での分け方

有効スキル値と武器のスキル値の内訳（仕様書 0007 の AC35）では、キャラクター由来の寄与を次のように分ける。

| 寄与元 | 値 |
|---|---|
| 基礎 | min(キャラクターのスキル値, マスターレベルを 0 としたスキル上限) |
| マスターレベル | min(キャラクターのスキル値, スキル上限) − 基礎 |
| メリットポイント | スキルのメリットポイントのランク × 2 |
| ギフト | ギフトのスキルボーナス |
