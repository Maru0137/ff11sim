# ジョブアビリティの書き方

`type: ジョブアビリティ` のナレッジの本文の形を定める。ジョブアビリティを 1 つ説明するときに使う。1 つのジョブアビリティにつき 1 本にする。ナレッジは `job_abilities/` に置く。
frontmatter・冒頭の文・末尾の節・出典などの共通の規則は [README.md](README.md) にある。

見本: [バーサク](../knowledge/job_abilities/berserk.md)

## 形

```markdown
---
type: ジョブアビリティ
title: "バーサク"
description: "<冒頭の定義を短く言い直した 1 文>"
status: draft
---

# バーサク

<タイトル> は、（<上位概念>のうち、 / <上位概念>の 1 つで、）…である。

_種別_: … / _上位_: … / _インスタンス元_: …

## ランク

## 効果時間と再使用時間

## 効き方

## 強化手段

## 歴史（任意）

## 未確認の事項

## 出典
```

## 本文の節

次の `##` をこの順にすべて置く。共通の規則（[README.md](README.md) の「本文の節」）のとおり、書くことが無いと確かめた節には「なし」と書き、まだ調べていない節は置かない。

| 節 | 書くこと |
|---|---|
| `## ランク` | ランクごとの習得レベルと効果値を 1 つの表にする。ゲーム内の表記と内部の値（256 分率など）が違うときは両方の列を置く |
| `## 効果時間と再使用時間` | 効果時間と再使用時間の基本の値 |
| `## 効き方` | 何に、どの段階で効くか（例: 攻撃力の乗算枠）。式の本体はステータスやゲームシステムの文書に置き、ここからリンクする |
| `## 強化手段` | 効果値・効果時間・再使用時間を変えるもの。メリットポイント・ジョブポイントと装備に分けて `###` を立てる |
