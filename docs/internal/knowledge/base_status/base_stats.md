# 基本ステータス

基本ステータスは、[ステータス](../../../../CONTEXT.md)のうち、HP・MP と、STR・DEX・VIT・AGI・INT・MND・CHR の 7 つの BP を合わせた 9 項目のことである。

_種別_: subkind
_上位_: ステータス
_排他_: 二次ステータス

## 効果

BP は、戦闘のいろいろな判定に影響する [1]。

| BP | 影響するもの [1] | 説明しているナレッジ |
|---|---|---|
| STR | 物理攻撃の与ダメージ | [近接物理攻撃力](../secondary_status/melee_attack.md)、[遠隔物理攻撃力](../secondary_status/ranged_attack.md) |
| DEX | 近接の命中、与クリティカル率 | [近接物理命中](../secondary_status/melee_accuracy.md) |
| VIT | 被ダメージ | [防御力](../secondary_status/defense.md) |
| AGI | 遠隔攻撃の命中、回避、被クリティカル率 | [遠隔物理命中](../secondary_status/ranged_accuracy.md)、[物理回避](../secondary_status/physical_evasion.md) |
| INT | 魔法攻撃の与ダメージ | — |
| MND | 弱体魔法・回復魔法 | — |
| CHR | 呪歌、あやつるの判定 | — |

## 計算式

### 基本ステータス

```
ステータス = floor(種族 + メインジョブ + サポートジョブ)
           + マスターレベルの補正
           + メリットポイントの補正
           + ジョブ特性の補正（HP と MP だけ）
           + 装備の合計
```

種族・メインジョブ・サポートジョブの 3 項は、足してからまとめて floor する。項ごとには floor しない。

#### 種族

種族のグレードとメインジョブのレベルから、グレードの式（「グレードの式」節）で求める。

#### メインジョブ

メインジョブのグレードとメインジョブのレベルから、グレードの式で求める。メインジョブがそのステータスのグレードを持たないときは 0 である。

#### サポートジョブ

サポートジョブのグレードとサポートジョブのレベルからグレードの式で求め、その半分を使う。

```
サポートジョブの項 = グレードの式(サポートジョブのグレード, サポートジョブのレベル) ÷ 2
```

サポートジョブのレベルは、次の上限で抑える。

```
サポートジョブのレベルの上限 = int(メインジョブのレベル ÷ 2) + int(マスターレベル ÷ 5)
```

例: メインジョブのレベル 99・マスターレベル 50 のとき、上限は 49 + 10 = 59 である。

#### マスターレベルの補正

| ステータス | マスターレベル 1 あたり |
|---|---|
| HP | +7 |
| MP | +2（メインジョブが MP のグレードを持つときだけ） |
| STR / DEX / VIT / AGI / INT / MND / CHR | +1 |

#### メリットポイントの補正

| ステータス | ランク 1 あたり | 最大ランク |
|---|---|---|
| HP | +10 | 15 |
| MP | +10 | 15 |
| STR / DEX / VIT / AGI / INT / MND / CHR | +1 | 15 |

#### ジョブ特性の補正（HP と MP だけ）

メインジョブとサポートジョブで習得したランクのうち、大きい方の値を使う。2 つを足さない。

| ジョブ特性 | 習得するジョブ | ランクごとの累積値 |
|---|---|---|
| 最大HPアップ | モンク・戦士・忍者・魔導剣士・ナイト | [30, 60, 120, 180, 240, 280] |
| 最大HPアップII | モンク | [150, 300, 450] |
| 最大MPアップ | 召喚士・学者・風水士 | [10, 20, 40, 60, 80, 100] |

例: 戦士99 は最大HPアップのランク 4（レベル 90 で習得）を持つので +180 である。

### グレードの式

```
グレードの式(grade, lv)
  = 基本値
  + floor(係数_2〜60 × min(lv − 1, 59) × 2) ÷ 2
  + floor(係数_61〜75 × clamp(lv − 60, 0, 15) × 2) ÷ 2
  + floor(係数_76〜99 × max(lv − 75, 0) × 2) ÷ 2
  + （HP と MP だけ）floor(係数_30〜 × max(lv − 30, 0) × 2) ÷ 2
```

各項に、0.5 単位の切り捨て（2 倍して floor し、2 で割る）を別々にかける。

#### グレードの係数

HP と MP:

|---|---|---|---|---|---|
| A | 19.0 | 9.0 | 3.0 | 3.0 | 1.0 |
| B | 17.0 | 8.0 | 3.0 | 3.0 | 1.0 |
| C | 16.0 | 7.0 | 3.0 | 3.0 | 1.0 |
| D | 14.0 | 6.0 | 3.0 | 3.0 | 0.0 |
| E | 13.0 | 5.0 | 2.0 | 2.0 | 0.0 |
| F | 11.0 | 4.0 | 2.0 | 2.0 | 0.0 |
| G | 10.0 | 3.0 | 2.0 | 2.0 | 0.0 |

STR / DEX / VIT / AGI / INT / MND / CHR:

| グレード | 基本値 | 2〜60 | 61〜75 | 76〜99 |
|---|---|---|---|---|
| A | 5.0 | 0.50 | 0.11 | 0.39 |
| B | 4.0 | 0.45 | 0.21 | 0.39 |
| C | 4.0 | 0.40 | 0.29 | 0.39 |
| D | 3.0 | 0.35 | 0.34 | 0.39 |
| E | 3.0 | 0.30 | 0.34 | 0.39 |
| F | 2.0 | 0.25 | 0.39 | 0.39 |

| 種族 | HP | MP | STR | DEX | VIT | AGI | INT | MND | CHR |

| ガルカ | A | G | C | D | A | E | E | D | F |

### MP グレードを持たないメインジョブ

メインジョブが MP のグレードを持たないとき、MP への種族・メインジョブ・マスターレベルの補正の寄与は 0 である。サポートジョブ・メリットポイント・ジョブ特性・装備の寄与はそのまま足す [2]。

MP のグレードを持たないジョブは、戦士・モンク・シーフ・獣使い・吟遊詩人・狩人・侍・忍者・竜騎士・コルセア・からくり士・踊り子である。

例: メインジョブが戦士でサポートジョブが白魔道士なら、MP はサポートジョブ（白魔道士の MP のグレードで求めて半分にした値）・MP のメリットポイント・装備の和になる。

## 計算例

ヒューム 戦士99 / 侍59、マスターレベル 50、基本ステータスのメリットポイントをすべて 15 振ったとき。装備を除く値を求める。

グレード:

- 戦士: HP=B、MP=なし、STR=A、DEX=C、VIT=D、AGI=C、INT=F、MND=F、CHR=E
- 侍: HP=B、MP=なし、STR=C、DEX=C、VIT=C、AGI=D、INT=E、MND=E、CHR=D
- ヒューム: すべて D

### STR

- 種族（ヒューム D、レベル 99）: 3 + floor(0.35×59×2)/2 + floor(0.34×15×2)/2 + floor(0.39×24×2)/2 = 3 + 20.5 + 5.0 + 9.0 = 37.5
- メインジョブ（戦士 A、レベル 99）: 5 + floor(0.50×59×2)/2 + floor(0.11×15×2)/2 + floor(0.39×24×2)/2 = 5 + 29.5 + 1.5 + 9.0 = 45.0
- サポートジョブ（侍 C、レベル 59）: (4 + floor(0.40×58×2)/2) ÷ 2 = (4 + 23.0) ÷ 2 = 13.5
- floor(37.5 + 45.0 + 13.5) = 96
- マスターレベル: 50 × 1 = 50
- メリットポイント: 15 × 1 = 15
- ジョブポイント・ギフト: STR への寄与は無い
- **STR（装備を除く）**: 96 + 50 + 15 = **161**

### HP

- 種族（ヒューム D、レベル 99）: 485
- メインジョブ（戦士 B、レベル 99）: 675
- サポートジョブ（侍 B、レベル 59）: 510 ÷ 2 = 255
- floor(485 + 675 + 255) = 1415
- マスターレベル: 50 × 7 = 350
- メリットポイント: 15 × 10 = 150
- ジョブ特性 最大HPアップ（戦士 ランク 4、レベル 90）: +180
- **HP（装備を除く）**: 1415 + 350 + 150 + 180 = **2095**

## 未確認の事項

- 計算式（「計算式」節のすべて）には出典が無い。書き直す前のこの文書は [FF11用語辞典 html/1697](https://wiki.ffo.jp/html/1697.html) を出典に挙げていたが、2026-10-31 に確かめると「投擲」のページで、基本ステータスについての記述は無かった。正しい出典は見つかっていない。マスターレベル・メリットポイント・ジョブ特性の補正の表も同じく出典が無い。
- HP と MP が何に影響するかは [1] に書かれていない。
- BP が影響するものの表は [1] の要約で、各 BP のページ（[1] からリンクされている）とは照合していない。
- 「MP グレードを持たないメインジョブ」の規則は [2] で決めた扱いで、ゲームの一次情報では確かめていない。メインジョブに MP が無いとき、種族の MP をサポートジョブのレベルで求める規則がゲームにあるかは分かっていない（仕様書 0007 の設計上の論点）。
- ジョブのグレードの表は、この文書に書いていない。計算例と「MP グレードを持たないメインジョブ」のジョブの一覧は ff11sim のデータ（`data/job_status_grades.json`）から取ったもので、ゲームの一次情報とは照合していない。
