# スキル上限と有効スキル値

スキル上限（あるスキルについて、今のメインジョブとサポートジョブで効くキャラクターのスキル値の上限）と、それを使った有効スキル値の求め方を記録する。語の定義は仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md) の「用語」節にある。

## ジョブ 1 つのスキル上限

```
ジョブのスキル上限(job, skill, lv, master_lv)
  = そのジョブがスキルのランクを持たないとき 0
  = lv が 0 以下のとき 0
  = それ以外のとき 補間値(ランク, min(lv, 99)) + max(master_lv, 0)
```

- ランク: ジョブとスキルの組ごとに決まる、`A+`〜`G` の値。ジョブがスキルを持たないときはランクも無い。
- 補間値: ランクごとの制御点（レベル 1・50・75・99）の値を線形補間し、四捨五入した値。

| ランク | レベル 1 | レベル 50 | レベル 75 | レベル 99 |
|---|---|---|---|---|
| A+ | 6 | 153 | 276 | 424 |
| A | 5 | 147 | 269 | 417 |
| B+ | 5 | 142 | 256 | 404 |
| B | 4 | 136 | 250 | 398 |
| B- | 4 | 126 | 240 | 388 |
| C+ | 4 | 116 | 230 | 378 |
| C | 4 | 101 | 225 | 373 |
| C- | 3 | 90 | 220 | 368 |
| D | 3 | 78 | 210 | 334 |
| E | 2 | 65 | 200 | 300 |
| F | 2 | 55 | 189 | 265 |
| G | 2 | 45 | 171 | 228 |

## スキル上限（メインジョブとサポートジョブの組）

```
スキル上限 = max(
  ジョブのスキル上限(メインジョブ, skill, メインジョブのレベル, マスターレベル),
  ジョブのスキル上限(サポートジョブ, skill, サポートジョブの有効レベル, 0)
)
```

- サポートジョブにはマスターレベルを足さない。
- サポートジョブの有効レベルは、[base_stats.md](base_stats.md) の「サポートジョブ」節の上限で抑えたレベル。サポートジョブを選んでいないとき、または有効レベルが 0 のとき、サポートジョブの項は 0 である。
- メリットポイントはスキル上限を広げない [1]。
- メインジョブとサポートジョブのどちらもスキルを持たないとき、スキル上限は 0 である。

## 有効スキル値

```
有効スキル値 = min(キャラクターのスキル値, スキル上限)
            + スキルのメリットポイントのランク × 2
            + 全スロット共通のスキルボーナス
            + ギフトのスキルボーナス
```

- メリットポイントの分（ランク 1 につき +2、ランク 8 で +16）は、スキル上限で抑えた後に足す。そのため有効スキル値はスキル上限を超えうる [1]。
- スキル上限が 0 のスキルにも、メリットポイントの分・装備のスキルボーナス・ギフトのスキルボーナスは足す。0 になるのはキャラクターのスキル値の分だけである [1]。
- 武器のスキル値は、この 4 つの和に、足し先がそのスロットであるスロット専用のスキルボーナスを足したものである。矢弾スロットの投てき武器のスキルボーナスは、足し先がレンジスロットである [1]。

## 計算例

メインジョブのレベル 99・マスターレベル 0 で、そのスキルのランクが A+（上限 424）、キャラクターのスキル値 424、スキルのメリットポイント 8 ランク、装備のスキルボーナス 0、ギフトのスキルボーナス 0 のとき:

```
有効スキル値 = min(424, 424) + 16 + 0 + 0 = 440
```

メインジョブが戦士・サポートジョブ無しで、歌唱スキル（戦士はランクを持たない）のメリットポイント 8 ランク、首の装備に歌唱スキル+10 があるとき、歌唱スキルの有効スキル値はキャラクターのスキル値によらず次のとおり:

```
有効スキル値 = 0 + 16 + 10 + 0 = 26
```

## ff11sim での扱い

- ランクは `data/job_skill_ranks.json`（`null` はスキルを持たない）、制御点は `data/skill_cap_control_points.json` に持つ。
- 有効スキル値と武器のスキル値の振り分け・内訳は、仕様書 0007 の AC22・AC26・AC35 で決めている。内訳では、キャラクター由来の寄与を、基礎（マスターレベルを 0 としたスキル上限で抑えた値）・マスターレベル（スキル上限で抑えた値から基礎を引いた残り）・メリットポイント・ギフトに分ける。
- キャラクターの編集フォームでのスキル値の入力上限は、ジョブレベルが 1 以上の各ジョブの「ジョブのスキル上限」の最大値で、メリットポイントは足さない（仕様書 [0002 キャラクターの管理](../../specs/0002-character-management.md) の「スキル値の入力上限」）。
- 実装はメリットポイントの扱いが [1] で改める前の規則のままである。食い違いは [tech-debt/status-knowledge-gaps.md](../../tech-debt/status-knowledge-gaps.md) にある。

## 未確認の事項

- メリットポイントをスキル上限で抑えた後に足すこと、スキル上限が 0 のスキルにも足すこと、スロット専用のスキルボーナスの足し先は [1] で決めた扱いで、ゲームの一次情報では確かめていない。
- ジョブとスキルのランク、ランクごとの制御点の値、線形補間して四捨五入する求め方の出典は、書き直し前から書かれていない。
