# 物理攻撃力

物理攻撃力は、[二次ステータス](secondary_status.md)のうち、物理攻撃の与ダメージに関わるもののことである [1]。
ジョブ特性とギフトの「物理攻撃力アップ」は、近接の攻撃力と遠隔の攻撃力（飛攻）の両方に効く [2]。

_種別_: subkind
_上位_: 二次ステータス
_排他_: 魔法攻撃力
_インスタンス_: 近接物理攻撃力、遠隔物理攻撃力

## 一覧

| 物理攻撃力 | ゲームの語 | 装備の表記 | ナレッジ |
|---|---|---|---|
| 近接物理攻撃力 | 攻撃力 | 攻+ | [近接物理攻撃力（攻撃力）](melee_attack.md) |
| 遠隔物理攻撃力 | 飛攻 | 飛攻+ | [遠隔物理攻撃力（飛攻）](ranged_attack.md) |

## 共通の規則

### 語の使い方

ゲームで「攻撃力」と言うときは、一般に近接攻撃の攻撃力（近接物理攻撃力）を指し、遠隔攻撃の攻撃力は「飛攻」と呼んで分ける [1][3]。
ナレッジでは、単独の「攻撃力」はゲームの語として近接物理攻撃力の名前の括弧の中（近接物理攻撃力（攻撃力））でだけ使い、飛攻を含む意味では「物理攻撃力」と書く。

### 武器のスキル値

近接物理攻撃力と遠隔物理攻撃力は、その武器のスキルについての武器のスキル値を使う。武器のスキル値は、そのスキルの有効スキル値に、
武器を着けたスロットのスロット専用のスキルボーナスを足したものである [4]。

```
武器のスキル値 = min(キャラクターのスキル値, スキル上限)
              + メリットポイントの分
              + 全スロット共通のスキルボーナス
              + ギフトのスキルボーナス
              + そのスロットのスキルボーナス
```

| 項 | 内容 |
|---|---|
| スキル上限 | メインジョブ（レベルとマスターレベル）とサポートジョブ（有効レベル。マスターレベルは足さない）のスキル上限の大きい方。メリットポイントでは広がらない（[スキル](skill.md)） |
| メリットポイントの分 | そのスキルのメリットポイントのランク × 2（ランク 0〜8、最大 +16）。スキル上限で抑えた後に足す |
| 全スロット共通のスキルボーナス | スロット専用でないすべてのスキル+。防具・盾・グリップ・楽器・風水鈴・投てき武器でない矢弾のもの、アイテムレベル装備でない武器のもの、アイテムレベル装備の武器が持つ自分以外のスキルのもの |
| ギフトのスキルボーナス | ギフトによるそのスキルのボーナス。武器のスキルのギフトは今のところ無いので 0 |
| そのスロットのスキルボーナス | そのスロットに着けた、アイテムレベル装備の武器が持つ、自分の武器のスキルのスキル+。矢弾スロットの投てき武器のものは、レンジスロットの武器のスキル値に足す |

武器スキル 1 につき攻撃力は 1 上がる [1]。

### 物理攻撃力ボーナス

近接物理攻撃力と遠隔物理攻撃力の両方に、同じ物理攻撃力ボーナスを足す。メイン・サブ・遠隔で構成は同じである。

```
物理攻撃力ボーナス = ジョブ特性「物理攻撃力アップ」（メインジョブとサポートジョブの大きい方）
                   + ギフト「物理攻撃力アップ」
                   + ジョブポイントのカテゴリの攻撃力
```

#### ジョブ特性「物理攻撃力アップ」

物理攻撃力にボーナスを得るジョブ特性である [5]。ランクごとの値は次のとおり [5]。

| ランク | 特性値 | 累積値 |
|---|---|---|
| 1 | +10 | +10 |
| 2 | +12 | +22 |
| 3 | +13 | +35 |
| 4 | +13 | +48 |
| 5 | +12 | +60 |
| 6 | +12 | +72 |
| 7 | +12 | +84 |
| 8 | +12 | +96 |

習得するジョブとレベルは次のとおり [5]。青魔道士は、青魔法のセットで得る追加特性として持つ [5]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| 暗黒騎士 | 10, 30, 50, 70, 76, 83, 91, 99 | 8（+96） |
| 戦士 | 30, 65, 91 | 3（+35） |
| 竜騎士 | 10, 91 | 2（+22） |
| 青魔道士（追加特性。最短のレベル） | 38, 63, 86, 99 | 4 |

#### ギフト「物理攻撃力アップ」

メインジョブの累計ジョブポイントに応じて段階が解放され、解放した段階の値の総和を足す [2][6]。物理と遠隔の両方の攻撃力に効く [2]。戦士の値は次のとおり [2]。

| 段階 | 解放する累計ジョブポイント | 値 | 総和 |
|---|---|---|---|
| 1 | 10 | +10 | +10 |
| 2 | 210 | +15 | +25 |
| 3 | 660 | +20 | +45 |
| 4 | 1360 | +25 | +70 |

#### ジョブポイントのカテゴリの攻撃力

一部のジョブの一部のカテゴリだけが、攻撃力に直接寄与する。戦士のカテゴリは攻撃力に寄与しない（0）。

### 計算の構造

物理攻撃力は 3 段階で求まる [7]。攻撃力の記事は、同じ順序を「(基本攻撃力 + 装備の攻撃力 + 固定値の攻撃力アップ) × 割合の攻撃力アップ + 食事」と書いている [1]。

```
攻撃力 = int(加算枠 × (256 + Σ乗算枠) ÷ 256) + 計算後加算枠
```

| 段階 | 内容 | 記録している場所 |
|---|---|---|
| 加算枠 | 基本の攻撃力（STR の項 + 武器のスキル値 + 8）、攻撃力+（ジョブ特性・装備・ジョブポイント・ギフト・イオニス）、歌 | [近接物理攻撃力](melee_attack.md)・[遠隔物理攻撃力](ranged_attack.md) と、この文書の「物理攻撃力ボーナス」 |
| 乗算枠 | ジョブ特性・アビリティ・支援魔法・ファントムロールによる割合の上昇 | この文書の「乗算枠の一覧」 |
| 計算後加算枠 | 食事、応援（チャチャルン） | この文書の「乗算枠に含まれないもの」 |

### 256 分率の原則

ゲームの内部では、乗算枠の割合をすべて 256 分率で扱う。ゲーム内に出る 100 分率の表記は人が読むための近似値で、100 分率のまま計算するとダメージがずれる [8]。

#### 表記揺れ

同じ 100 分率の表記でも、256 分率の値が違うことがある。そのため 100 分率の表記からは 256 分率の値を決められず、項目ごとに実測された値を持つ必要がある [8]。

| 例 | 100 分率 | 256 分率 | 実効値 |
|---|---|---|---|
| 青魔法 N.メディテイト | +20% | 52/256 | +20.31% |
| 青魔法 カルカリアンヴァーヴ | +20% | 51/256 | +19.92% |

#### 丸め規則

100 分率から 256 分率への丸めは、項目ごとに一定でない。切り捨て（`floor(表記% × 256 ÷ 100)`）に一致する項目が多いが、四捨五入に当たる項目も混じる [8]。

- 切り捨ての例: スマイト +20% → 51.2 → 51
- 四捨五入の例: N.メディテイト +20% → 51.2 → 52

### 乗算枠どうしの合成

乗算枠どうしは足して合成する。項目ごとに倍率を求めてから足しても、結果は同じである [8]。

```
倍率 = (256 + Σ 各項目の 256 分率の値) ÷ 256
```

例: スマイト ランク5（76）+ バーサク ランク6（89）+ ラストリゾート メリットポイント 5 振り（89）のとき、
倍率は (256 + 76 + 89 + 89) ÷ 256 = 510/256（+99.2%）になる。

#### ファントムロール

カオスロールは乗算枠に入るが、効果が複雑で、[8] でも「別紙を参照」とされている。値はまだ調べていない。

### 乗算枠に含まれないもの

| 項目 | 扱い |
|---|---|
| 攻+N の実数値（装備・ギフト・ジョブ特性「攻撃力アップ」・ジョブポイント・イオニス） | 加算枠 |
| 歌（メヌエット・栄典の戴冠マーチ・剛力・怪力） | 加算枠 |
| 食事 | 計算後加算枠。乗算の影響を受けず、すべての計算の後に足す |
| 応援（チャチャルン） | 計算後加算枠。食事と同じ |

食事と応援のうち、STR の上昇分は STR に足すので、乗算の影響を受ける。乗算の影響を受けないのは、攻撃力に直接足す分だけである [10]。

## 未確認の事項

- 乗算枠の 256 分率の値は [8] だけに基づき、[1] やゲーム内の実測と照合していない。
- ウォークライの分母を 256 に直したのは判断で、[8] の作者には確かめていない。
- 「計算の構造」の式・「乗算枠に含まれないもの」・食事の STR の扱いが [7]・[10] のどちらに基づくかは照合していない。
- スマイトとバーサク以外の乗算枠の項目が、遠隔物理攻撃力に効くかは調べていない。
- 武器のスキル値の式（メリットポイントをスキル上限で抑えた後に足すこと、全スロット共通のスキルボーナスとスロット専用のスキルボーナスの振り分け）は [4] で決めた扱いで、ゲームの一次情報では確かめていない。
- 「攻撃力」が一般に近接攻撃の攻撃力を指すことは、[1] が近接の武器の式を中心に書き、[3] が遠隔攻撃の攻撃力を「飛攻」と呼ぶことからの推論で、明記された出典は無い。
- ギフト「物理攻撃力アップ」は戦士の値だけを確かめた。戦士のジョブポイントのカテゴリが攻撃力に寄与しないことの出典は無い。
- メインジョブとサポートジョブのランクの大きい方を使うことの出典は無い。
- [1][5][2][9] は WebFetch で要約して読んだもので、原文を目で確かめていない。
