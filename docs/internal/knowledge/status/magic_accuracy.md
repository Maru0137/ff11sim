# 魔命 (Magic Accuracy)

「魔命」という語が指す 2 つの値と、ウェポンスキルの追加効果・魔法のレジストの判定に使う魔命の求め方を記録する。

## 2 つの「魔命」

「魔命」という語は、ゲームでは区別されずに 2 つの値を指す。

| 値 | 内容 |
|---|---|
| 魔命の加算値 | 装備の「魔命+」、ジョブ特性「魔法命中率アップ」、ギフト「魔法命中アップ」、ジョブポイントのカテゴリの合計 |
| 実効の魔命 | ウェポンスキルの追加効果・属性ウェポンスキル・魔法のレジストの判定に使う値（次節） |

## 実効の魔命

```
実効の魔命 = 魔命の加算値 + メインの武器の魔命スキル + そのスキルのスキル値
```

- **そのスキルのスキル値**: ウェポンスキルでは、その武器（メインまたはレンジ）の武器のスキル値。魔法では、その魔法の種類のスキル値。
- **メインの武器の魔命スキル**: メインスロットの装備が持つ「魔命スキル+」の値。ほかのスロットの装備の魔命スキル+ は足さない。
- dINT / dMND・天候・曜日・魔命ブーストなどの補正はこの式に含まない。

## 魔法の種類ごとの例外

### 呪歌

```
実効の魔命（呪歌）= 魔命の加算値 + メインの武器の魔命スキル + 歌唱スキル + 管楽器スキル（管楽器を装備しているときだけ）
```

レンジスロットに管楽器を装備しているときは管楽器スキルを足す。弦楽器を装備しているときは、弦楽器スキルを足さない。

### 風水魔法

```
実効の魔命（風水）= 魔命の加算値 + メインの武器の魔命スキル + 風水魔法スキル + 風水鈴スキル（風水鈴を装備しているときだけ）
```

風水鈴スキルは、レンジスロットに風水鈴を装備しているときだけ足す。

## ff11sim での扱い

- 画面では、魔命の加算値を「魔命+」、実効の魔命を「魔命」（「+」なし）と書き分ける。攻撃・命中・飛攻・飛命も「ステータス + スキル + 装備」の実効の値で「+」なしで書くので、魔命をその魔法版とした。同じ規約で「魔法ダメージ+」は「+」付きで書き、ウェポンスキルのダメージは「WSD」と書く。以前の名前「魔命合計」は使わない。
- 実効の魔命は dINT / dMND などの補正を含まない近似の値である。命中の表示が食事や支援を含まないのと同じ扱いにした。
- レンジの武器の実効の魔命は、ウェポンスキルを撃てる弓術・射撃の武器を装備しているときだけ出す。楽器・投てき・未装備のときは、その行ごと出さない。レンジの装備の種類は、アイテムの skill ID から決まるスキル（Archery / Marksmanship / Throwing / StringInstrument / WindInstrument / Handbell）で判定する。呪歌の行では、レンジスロットの楽器の種類（弦楽器か管楽器か）で、出すスキルを切り替える。
- 計算は `web/src/status/compute.ts` の `maccTotals` にまとめている。組み込みプロパティの id は、実効の魔命が `macc_main` / `macc_ranged`（武器のスキル値を使うもの）と `macc_divine`〜`macc_geomancy`（魔法のスキル値を使うもの）、魔命スキルが `macc_skill_main` / `macc_skill_sub`、魔命の加算値が `magic_accuracy` である。
- 魔命スキルと実効の魔命は、スロットに依存する合成の値なので内訳を求めない（仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md) の AC39、[ADR 0016](../../adr/0016-status-breakdown-modal.md)）。
