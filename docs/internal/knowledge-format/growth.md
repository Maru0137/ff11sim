# 育成の書き方

`type: 育成` のナレッジの本文の形を定める。キャラクターが育成で得る値（メリットポイント・ジョブポイント・ギフト・マスターレベルなど）を説明するときに使う。ナレッジは `growth/` に置く。
frontmatter・冒頭の文・末尾の節・出典などの共通の規則は [README.md](README.md) にある。

見本: [メリットポイント](../knowledge/growth/merit_points.md)

## 形

```markdown
---
type: 育成
title: "メリットポイント"
description: "<冒頭の定義を短く言い直した 1 文>"
status: draft
---

# メリットポイント

<タイトル> は、（<上位概念>のうち、 / <上位概念>の 1 つで、）…である。

_種別_: … / _上位_: … / _インスタンス元_: …

## 得かた

## 上限

## 効果

## 歴史（任意）

## 未確認の事項

## 出典
```

## 本文の節

次の `##` をこの順にすべて置く。共通の規則（[README.md](README.md) の「本文の節」）のとおり、書くことが無いと確かめた節には「なし」と書き、まだ調べていない節は置かない。

| 節 | 書くこと |
|---|---|
| `## 得かた` | その値をどうやって得るか |
| `## 上限` | 得られる量・割り振れる量の上限 |
| `## 効果` | 割り振った値が何に効くか。効く先のステータスやジョブアビリティの文書へリンクする |
