# 基本ステータス (HP / MP / STR / DEX / VIT / AGI / INT / MND / CHR)

キャラクターの基本ステータス 9 種の計算式と、種族・ジョブのグレードの値を記録する。

## 計算式

```
ステータス = floor(種族 + メインジョブ + サポートジョブ)
           + マスターレベルの補正
           + メリットポイントの補正
           + ジョブ特性の補正（HP と MP だけ）
           + 装備の合計
```

種族・メインジョブ・サポートジョブの 3 項は、足してからまとめて floor する。項ごとには floor しない [1]。

### 種族

種族のグレードとメインジョブのレベルから、グレードの式（「グレードの式」節）で求める [1]。

### メインジョブ

メインジョブのグレードとメインジョブのレベルから、グレードの式で求める。メインジョブがそのステータスのグレードを持たないときは 0 である [1]。

### サポートジョブ

サポートジョブのグレードとサポートジョブのレベルからグレードの式で求め、その半分を使う [1]。

```
サポートジョブの項 = グレードの式(サポートジョブのグレード, サポートジョブのレベル) ÷ 2
```

サポートジョブのレベルは、次の上限で抑える [1]。

```
サポートジョブのレベルの上限 = int(メインジョブのレベル ÷ 2) + int(マスターレベル ÷ 5)
```

例: メインジョブのレベル 99・マスターレベル 50 のとき、上限は 49 + 10 = 59 である。

### マスターレベルの補正

| ステータス | マスターレベル 1 あたり |
|---|---|
| HP | +7 |
| MP | +2（メインジョブが MP のグレードを持つときだけ） |
| STR / DEX / VIT / AGI / INT / MND / CHR | +1 |

### メリットポイントの補正

| ステータス | ランク 1 あたり | 最大ランク |
|---|---|---|
| HP | +10 | 15 |
| MP | +10 | 15 |
| STR / DEX / VIT / AGI / INT / MND / CHR | +1 | 15 |

### ジョブ特性の補正（HP と MP だけ）

メインジョブとサポートジョブで習得したランクのうち、大きい方の値を使う。2 つを足さない。

| ジョブ特性 | 習得するジョブ | ランクごとの累積値 |
|---|---|---|
| 最大HPアップ | モンク・戦士・忍者・魔導剣士・ナイト | [30, 60, 120, 180, 240, 280] |
| 最大HPアップII | モンク | [150, 300, 450] |
| 最大MPアップ | 召喚士・学者・風水士 | [10, 20, 40, 60, 80, 100] |

例: 戦士99 は最大HPアップのランク 4（レベル 90 で習得）を持つので +180 である。

## グレードの式

```
グレードの式(grade, lv)
  = 基本値
  + floor(係数_2〜60 × min(lv − 1, 59) × 2) ÷ 2
  + floor(係数_61〜75 × clamp(lv − 60, 0, 15) × 2) ÷ 2
  + floor(係数_76〜99 × max(lv − 75, 0) × 2) ÷ 2
  + （HP と MP だけ）floor(係数_30〜 × max(lv − 30, 0) × 2) ÷ 2
```

各項に、0.5 単位の切り捨て（2 倍して floor し、2 で割る）を別々にかける [1]。

## 特殊なケース

### MP グレードを持たないメインジョブ

メインジョブが MP のグレードを持たないとき、MP への種族・メインジョブ・マスターレベルの補正の寄与は 0 である。サポートジョブ・メリットポイント・ジョブ特性・装備の寄与はそのまま足す [2]。

MP のグレードを持たないジョブは、戦士・モンク・シーフ・獣使い・吟遊詩人・狩人・侍・忍者・竜騎士・コルセア・からくり士・踊り子である（`data/job_status_grades.json` で `Mp` が `null`）。

例: メインジョブが戦士でサポートジョブが白魔道士なら、MP はサポートジョブ（白魔道士の MP のグレードで求めて半分にした値）・MP のメリットポイント・装備の和になる。

## 計算例

ヒューム 戦士99 / 侍59、マスターレベル 50、基本ステータスのメリットポイントをすべて 15 振ったとき。装備を除く値を求める。

グレード:

- 戦士: HP=B、MP=なし、STR=A、DEX=C、VIT=D、AGI=C、INT=F、MND=F、CHR=E
- 侍: HP=B、MP=なし、STR=C、DEX=C、VIT=C、AGI=D、INT=E、MND=E、CHR=D
- ヒューム: すべて D

### STR

- 種族（ヒューム D、レベル 99）: 3 + floor(0.35×59×2)/2 + floor(0.34×15×2)/2 + floor(0.39×24×2)/2 = 3 + 20.5 + 5.0 + 9.0 = 37.5
- メインジョブ（戦士 A、レベル 99）: 5 + floor(0.50×59×2)/2 + floor(0.11×15×2)/2 + floor(0.39×24×2)/2 = 5 + 29.5 + 1.5 + 9.0 = 45.0
- サポートジョブ（侍 C、レベル 59）: (4 + floor(0.40×58×2)/2) ÷ 2 = (4 + 23.0) ÷ 2 = 13.5
- floor(37.5 + 45.0 + 13.5) = 96
- マスターレベル: 50 × 1 = 50
- メリットポイント: 15 × 1 = 15
- ジョブポイント・ギフト: STR への寄与は無い
- **STR（装備を除く）**: 96 + 50 + 15 = **161**

### HP

- 種族（ヒューム D、レベル 99）: 485
- メインジョブ（戦士 B、レベル 99）: 675
- サポートジョブ（侍 B、レベル 59）: 510 ÷ 2 = 255
- floor(485 + 675 + 255) = 1415
- マスターレベル: 50 × 7 = 350
- メリットポイント: 15 × 10 = 150
- ジョブ特性 最大HPアップ（戦士 ランク 4、レベル 90）: +180
- **HP（装備を除く）**: 1415 + 350 + 150 + 180 = **2095**

## ff11sim での扱い

- ジョブのグレードは `data/job_status_grades.json` を正とする（[ADR 0002](../../adr/0002-shared-table-data-json.md)）。種族のグレードは `rust/src/race.rs` の `STATUS_GRADES` に持つ。
- サポートジョブの有効レベルと MP の扱いは、仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md) の「用語」節と AC32 で決めている。
- ゲームにはあるが計算していない項目は [tech-debt/status-knowledge-gaps.md](../../tech-debt/status-knowledge-gaps.md) にある。
