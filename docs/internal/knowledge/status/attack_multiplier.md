# 攻撃力の乗算枠

攻撃力の計算構造のうち、加算枠に掛ける割合の上昇（乗算枠）を記録する。加算枠（基本の攻撃力・攻撃力+・歌）は [attack.md](attack.md) にある。

## 攻撃力の計算構造

攻撃力は 3 段階で求まる [1]。

```
攻撃力 = int(加算枠 × (256 + Σ乗算枠) ÷ 256) + 計算後加算枠
```

| 段階 | 内容 | 記録している場所 |
|---|---|---|
| 加算枠 | 基本の攻撃力（武器のスキル値 + STR + 8）、攻撃力+（ジョブ特性・装備・ジョブポイント・ギフト・イオニス）、歌 | [attack.md](attack.md) |
| 乗算枠 | ジョブ特性・アビリティ・支援魔法・ファントムロールによる割合の上昇 | この文書 |
| 計算後加算枠 | 食事、応援（チャチャルン） | この文書の「乗算枠に含まれないもの」 |

## 256 分率の原則

ゲームの内部では、乗算枠の割合をすべて 256 分率で扱う。ゲーム内に出る 100 分率の表記は人が読むための近似値で、100 分率のまま計算するとダメージがずれる [2]。

### 表記揺れ

同じ 100 分率の表記でも、256 分率の値が違うことがある。そのため 100 分率の表記からは 256 分率の値を決められず、項目ごとに実測された値を持つ必要がある [2]。

| 例 | 100 分率 | 256 分率 | 実効値 |
|---|---|---|---|
| 青魔法 N.メディテイト | +20% | 52/256 | +20.31% |
| 青魔法 カルカリアンヴァーヴ | +20% | 51/256 | +19.92% |

### 丸め規則

100 分率から 256 分率への丸めは、項目ごとに一定でない。切り捨て（`floor(表記% × 256 ÷ 100)`）に一致する項目が多いが、四捨五入に当たる項目も混じる [2]。

- 切り捨ての例: スマイト +20% → 51.2 → 51
- 四捨五入の例: N.メディテイト +20% → 51.2 → 52

## 乗算枠どうしの合成

乗算枠どうしは足して合成する。項目ごとに倍率を求めてから足しても、結果は同じである [2]。

```
倍率 = (256 + Σ 各項目の 256 分率の値) ÷ 256
```

例: スマイト ランク5（76）+ バーサク ランク6（89）+ ラストリゾート メリットポイント 5 振り（89）のとき、
倍率は (256 + 76 + 89 + 89) ÷ 256 = 510/256（+99.2%）になる。

### ファントムロール

カオスロールは乗算枠に入るが、効果が複雑で、[2] でも「別紙を参照」とされている。値はまだ調べていない。

## 乗算枠に含まれないもの

| 項目 | 扱い |
|---|---|
| 攻+N の実数値（装備・ギフト・ジョブ特性「攻撃力アップ」・ジョブポイント・イオニス） | 加算枠 |
| 歌（メヌエット・栄典の戴冠マーチ・剛力・怪力） | 加算枠 |
| 食事 | 計算後加算枠。乗算の影響を受けず、すべての計算の後に足す |
| 応援（チャチャルン） | 計算後加算枠。食事と同じ |

食事と応援のうち、STR の上昇分は STR に足すので、乗算の影響を受ける。乗算の影響を受けないのは、攻撃力に直接足す分だけである [3]。

## ff11sim での扱い

ff11sim は乗算枠と計算後加算枠を計算していない。攻撃力は加算枠だけで求める。乗算枠を入れるときの方針（256 分率の値を項目ごとに表で持ち、100 分率から換算しない）と食い違いは [tech-debt/status-knowledge-gaps.md](../../tech-debt/status-knowledge-gaps.md) にある。
