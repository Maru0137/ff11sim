# 装備スロットの名称

キャラクターが装備品を着ける枠（スロット）は 16 個ある。このファイルは、ゲームでの各スロットの名称と、武器のスロットと矢弾のスロットに着けられるものの関係を記録する。

## 名称の対応

「名称」と英語名は [1] の表記に従う。

| 名称 | 英語名 | ff11sim の表示名 | `key` |
|---|---|---|---|
| メインウェポン | Main | メイン | `main` |
| サブウェポン | Sub | サブ | `sub` |
| レンジウェポン | Range | レンジ | `range` |
| 矢弾 | Ammo | 矢弾 | `ammo` |
| 頭 | Head | 頭 | `head` |
| 首 | Neck | 首 | `neck` |
| 左耳 | Ear1 / L.ear | 左耳 | `ear1` |
| 右耳 | Ear2 / R.ear | 右耳 | `ear2` |
| 胴 | Body | 胴 | `body` |
| 両手 | Hands | 両手 | `hands` |
| 左手の指 | Ring1 / L.ring | 左指 | `ring1` |
| 右手の指 | Ring2 / R.ring | 右指 | `ring2` |
| 背 | Back | 背 | `back` |
| 腰 | Waist | 腰 | `waist` |
| 両脚 | Legs | 両脚 | `legs` |
| 両足 | Feet | 両足 | `feet` |

名称と ff11sim の表示名が違うのは、メインウェポン・サブウェポン・レンジウェポン・左手の指・右手の指の 5 つである。ほかの 11 個は名称をそのまま表示名にしている。

## 武器スロットと矢弾の関係

- レンジウェポンには、弓・射撃の発射台・ブーメランなどの非消費型の投てき武器・楽器・釣り竿を着ける [2][1]。
- 矢弾には、矢・ボルト・弾・消費型の投てき武器（手裏剣など）・釣り餌を着ける [2][1]。
- 矢・ボルト・弾・釣り餌はレンジウェポンと併用する設計である。消費型の投てき武器は、レンジウェポンに非消費型の投てき武器を着けているときは使えない [2]。
- レンジウェポンに何かを着けているとき、矢弾に投てき武器（手裏剣など）は着けられない。非消費型の投てき武器・弓・銃・楽器・風水鈴・釣り竿のどれを着けているときも同じである [3]。
- したがって、矢弾に投てき武器を着けているとき、レンジウェポンはいつも空で、その投てき武器が遠隔攻撃に使う武器になる。

## ff11sim での扱い

- 表示名と `key` は [data/equipment_slots.json](../../../../data/equipment_slots.json) の `label_ja` と `key` に持つ。
- 矢弾の投てき武器の扱いは、仕様書 [0003 の用語「遠隔攻撃に使う武器」](../../specs/0003-status-view-management.md) と、仕様書 [0007](../../specs/0007-status-calculation.md) の「スロット専用のスキルボーナス」とスコープ外で決めている。

## 未確認の事項

- [1] と [2] は有志が運営する辞典で、スクウェア・エニックスの公式資料ではない。ゲーム内の装備画面での表記とは照合していない。
- 指の名称は [1] の「左手の指」「右手の指」を採った。ゲーム内の表記が同じかは確かめていない。
- 矢弾の投てき武器とレンジウェポンを併用できない規則 [3] は、ユーザーが投てき武器・弓・銃・楽器・風水鈴・釣り竿について確かめたもので、ゲーム内の画面での照合はしていない。
