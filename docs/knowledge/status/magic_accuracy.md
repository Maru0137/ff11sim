# 魔命 (Magic Accuracy) 計算仕様

## 2 つの「魔命」概念

「魔命」という語には公式に区別されない 2 つの概念があり、本プロジェクトの UI では「+」の有無で区別する:

| 表記 | 概念 | 内容 |
|---|---|---|
| **魔命+** | 加算プロパティ | 装備の「魔命+」+ ジョブ特性「魔法命中率アップ」+ ギフト「魔法命中アップ」+ JP カテゴリの合算 |
| **魔命** (無印) | 実効魔命 | WS 追加効果・属性 WS・魔法のレジスト判定に使われる値 (下式) |

> ※ 旧称「魔命合計」は廃止。テンプレートの攻撃/命中/飛攻/飛命も「ステータス + スキル + 装備」の実効値で無印表記のため、魔命はその魔法版という整理。

## 実効魔命の計算式

```
実効魔命 = 魔命+ + メイン武器スロットの魔命スキル + 当該スキル値
```

- **当該スキル値** はスキル供給元によって変わる:
  - WS 系: 各行の武器スキル値 (メイン/レンジ)
  - 魔法系: その魔法種別のスキル値
- **魔命スキル** は装備説明文の「魔命スキル+」抽出値で、メイン武器スロット装備分のみ計上する
- 表示値は dINT/MND・天候・曜日・魔命ブースト等の補正を含まない近似
  (命中表示が食事・支援を含まないのと同レベルの扱い)

## 種別ごとの特例

### 呪歌

```
実効魔命(呪歌) = 魔命+ + メイン魔命スキル + 歌唱スキル + 管楽器スキル(管楽器装備時のみ)
```

- レンジスロットの楽器種別でスキル表示を切替 (弦楽器 or 管楽器)
- **弦楽器はスキル表示のみで実効魔命には加算しない** (加算されるのは管楽器のみ)

### 風水魔法

```
実効魔命(風水) = 魔命+ + メイン魔命スキル + 風水魔法スキル + 風水鈴スキル(レンジに風水鈴装備時のみ)
```

- 風水鈴スキルの表示・加算はレンジスロットに風水鈴を装備している場合のみ

### WS 系のレンジ行

- レンジ武器の実効魔命は WS を撃てる弓術/射撃の装備時のみ算出・表示
  (楽器・投てき・未装備ではレンジ行ごと非表示)
- レンジ装備の種別判定はアイテムの skill ID 由来のスキルキー
  (Archery / Marksmanship / Throwing / StringInstrument / WindInstrument / Handbell)

## 実装メモ

- 計算は `web/src/status/compute.ts` の `maccTotals: Record<'main' | 'ranged' | 魔法種別, number>` に集約
- カタログ項目 id は実効魔命ファミリーを `macc_{対象}` で統一:
  - `macc_main` / `macc_ranged` (武器スキル値ベース)、`macc_divine` 〜 `macc_geomancy` (魔法スキル値ベース)
  - 魔命スキルは `macc_skill_main` / `macc_skill_sub`
  - 魔命+ は `magic_accuracy`
- 魔命スキル/実効魔命の項目は内訳モーダル非対応 (スロット依存の合成値のため `BREAKDOWN_UNSUPPORTED_IDS` に明示)
- 同じ「+」規約で「魔法ダメージ+」も + 付き表記、WS ダメージは「WSD」表記
