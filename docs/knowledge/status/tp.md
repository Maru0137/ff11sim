# 得TP (TP/hit) 計算仕様

参考: [wiki.ffo.jp/html/8311.html](https://wiki.ffo.jp/html/8311.html) /
[Tactical Points - BG Wiki](https://www.bg-wiki.com/ffxi/Tactical_Points)

1 ヒットで得られる TP。攻撃に使った武器の**隔**とストアTPで決まる。

```
得TP = int(隔による基本値 × (100 + ストアTP) ÷ 100)
```

## 隔による基本値

`int()` は小数点以下切り捨て。基本値の下限は 40。

| 隔 | 基本値 |
|---|---|
| 〜180 | 61 + int((隔 − 180) × 63 ÷ 360) |
| 181〜540 | 61 + int((隔 − 180) × 88 ÷ 360) |
| 541〜630 | 149 + int((隔 − 540) × 20 ÷ 360) |
| 631〜720 | 154 + int((隔 − 630) × 28 ÷ 360) |
| 721〜900 | 161 + int((隔 − 720) × 24 ÷ 360) |
| 901〜 | 173 + int((隔 − 900) × 28 ÷ 360) |

隔 180 以下は係数が小さく (63/360)、隔を短くしても得TPはあまり落ちない。
逆に 181〜540 は 88/360 と大きい。

## 使う隔

武器構成によって、基本値に入れる隔が変わる。

| 構成 | 隔 |
|---|---|
| 片手/両手 (サブスロットに武器なし) | メイン武器の隔 |
| 二刀流 (サブスロットに隔を持つ武器) | int((メイン隔 + サブ隔) × (100 − 二刀流) ÷ 100 ÷ 2) |
| 格闘 (メインが格闘武器 / 素手) | int((480 + メイン武器の隔 − マーシャルアーツ) ÷ 2) |
| 遠隔 (弓術/射撃/投てき) | レンジ武器の隔 + 矢弾の隔 |

- **二刀流・格闘の ÷2**: どちらも 1 回の攻撃ラウンドで 2 回判定が入るため、
  1 ヒットあたりの隔は攻撃間隔の半分になる。両手とも同じ値になり、
  メイン/サブで得TPは変わらない。
- **格闘の 480**: 格闘の基本隔。装備の説明文にある `隔+N` は 480 への加算量
  (アイテムデータの `delay` フィールドは 240 + N なので、説明文から抽出した値を使う)。
- **マーシャルアーツ**: 格闘の攻撃間隔短縮量。ジョブ特性 (Mnk/Pup) +
  ギフト「マーシャルアーツ効果アップ」+ 装備の「マーシャルアーツ+N」の合計。
- **二刀流**: 攻撃間隔の短縮率 (%)。ジョブ特性 (Thf/Nin/Dnc) +
  ギフト「二刀流効果アップ」+ 装備の「二刀流+N」の合計。
  数値を持たない「二刀流効果アップ」「二刀流性能アップ」表記の装備は加算できない。
- **遠隔**: 矢弾の隔は攻撃間隔には影響しないが、得TPには加算される。

## 本プロジェクトでの扱い

- 実装: `rust/src/status.rs` の `calc_tp_per_hit` / `calc_melee_tp_delay` /
  `calc_ranged_tp_delay`。総合値の組み立ては `rust/src/wasm.rs` の
  `chara_to_status_result` (`tp_per_hit_melee` / `tp_per_hit_ranged`)。
- 表示は 1 ヒットあたりの値。マルチアタック (DA/TA/QA、ダブル/トリプルショット) の
  発生は考慮せず、WS も 1 ヒット前提で同じ値を出す
  (多段 WS のヒット数は WS を指定しないと決まらないため)。
- 遠隔の得TPはレンジスロットが弓術/射撃/投てきのときだけ出す。
  楽器・風水鈴は遠隔攻撃をしないためダッシュ表示。
- 未対応: インヒビットTP (敵の与TPダウン)、アビリティによる隔短縮 (フェンシング等)。
- ヘイストは攻撃間隔を縮めるだけで得TPには影響しない (計算に入れない)。
