# 近接物理攻撃力（攻撃力）

近接物理攻撃力は、[物理攻撃力](physical_attack.md)の 1 つで、近接攻撃の与ダメージに関わる値である。ゲームでは「攻撃力」と呼ぶ [1]。

_インスタンス元_: 物理攻撃力
_排他_: 遠隔物理攻撃力

## 効果

物理攻撃のダメージの計算では、攻撃する側の攻撃力を防御する側の防御力で割った値（攻防比）を使う [2]。
近接物理攻撃力は、近接攻撃の攻防比の分子になる。防御力は [防御力](defense.md) にある。

ステータス画面に出るのはメインの武器の攻撃力だけで、サブの武器の攻撃力は `/checkparam` で確かめる [1]。

## 計算式

### 近接物理攻撃力

メインの武器とサブの武器で、それぞれ求める [1]。

```
近接物理攻撃力 = STR の項 + 武器のスキル値 + 8 + 装備の攻 + 物理攻撃力ボーナス
```

| 項 | 内容 |
|---|---|
| STR の項 | 武器とスロットで係数が変わる（「STR の項」節） |
| 武器のスキル値 | その武器のスキルの武器のスキル値（[物理攻撃力](physical_attack.md) の「武器のスキル値」） |
| 装備の攻 | 装備の「攻+」の合計 |
| 物理攻撃力ボーナス | ジョブ特性・ギフト・ジョブポイントのカテゴリによるボーナス。遠隔物理攻撃力と共通（[物理攻撃力](physical_attack.md) の「物理攻撃力ボーナス」） |

この式は加算枠で、これに乗算枠を掛け、計算後加算枠を足したものが最終の攻撃力になる（[物理攻撃力](physical_attack.md) の「計算の構造」）。

### STR の項

| 武器 | STR の項 |
|---|---|
| メインの片手武器・両手武器 | STR |
| 格闘（メイン・サブ） | int(STR × 0.75) |
| サブの片手武器 | int(STR × 0.5) |

`int()` は小数点以下の切り捨て [1]。両手武器はサブスロットに着けられないので、サブの両手武器は無い。

## 計算例

ヒューム 戦士99 / 侍59、マスターレベル50、ラフリア装備セットのメインの近接物理攻撃力（加算枠）:

- STR（装備込み）= 161 + 247 = 408
- 両手斧の武器のスキル値 = 490 + 277（メインスロットのラフリア）+ 21（全スロット共通、BI ロリカ）= 788。
  490 は min(キャラクターのスキル値, スキル上限 424 + マスターレベル 50 = 474) + メリットポイント 16 で、キャラクターのスキル値が 474 以上のときの値。
- 装備の攻 = 448
- 物理攻撃力ボーナス = 35（戦士のジョブ特性ランク 3）+ 70（ギフト、2100 JP）+ 0（ジョブポイントのカテゴリ）= 105

```
近接物理攻撃力 = 408 + 788 + 8 + 448 + 105
              = 1757
```
