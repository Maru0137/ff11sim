# ゲームシステムの書き方

`type: ゲームシステム` のナレッジの本文の形を定める。ステータス・ジョブ特性・装備などを入力にしてゲームが行う計算や処理（得TP・攻防比・ダメージなど）を説明するときに使う。ナレッジは `game_system/` に置く。
frontmatter・冒頭の文・末尾の節・出典などの共通の規則は [README.md](README.md) にある。

見本: [得TP](../knowledge/game_system/tp.md)

## 形

```markdown
---
type: ゲームシステム
title: "得TP"
description: "<冒頭の定義を短く言い直した 1 文>"
status: draft
---

# 得TP

<タイトル> は、（<上位概念>のうち、 / <上位概念>の 1 つで、）…である。

_種別_: … / _上位_: … / _インスタンス元_: …

## 仕組み

## 計算式

## 計算例

## 歴史（任意）

## 未確認の事項

## 出典
```

## 本文の節

次の `##` をこの順にすべて置く。共通の規則（[README.md](README.md) の「本文の節」）のとおり、書くことが無いと確かめた節には「なし」と書き、まだ調べていない節は置かない。

| 節 | 書くこと |
|---|---|
| `## 仕組み` | どんな場面で何が起きるか（例: 得TP なら、どの行動で TP が増えるか） |
| `## 計算式` | 値の求め方。式ごとに `###` を立てる |
| `## 計算例` | 具体的な入力と、式に当てはめた途中の値と結果 |
