# 基本ステータスの書き方

`type: 基本ステータス` のナレッジの本文の形を定める。基本ステータス（HP・MP と BP の 9 項目）の 1 つ、または 9 項目全体を説明するときに使う。ナレッジは `base_status/` に置く。
frontmatter・冒頭の文・末尾の節・出典などの共通の規則は [README.md](README.md) にある。

見本: [基本ステータス](../knowledge/base_status/base_stats.md)

## 形

```markdown
---
type: 基本ステータス
title: "基本ステータス"
description: "<冒頭の定義を短く言い直した 1 文>"
status: draft
---

# 基本ステータス

<タイトル> は、（<上位概念>のうち、 / <上位概念>の 1 つで、）…である。

_種別_: … / _上位_: … / _インスタンス元_: …

## 効果

## 計算式

## 計算例

## 歴史（任意）

## 未確認の事項

## 出典
```

## 本文の節

次の `##` をこの順にすべて置く。共通の規則（[README.md](README.md) の「本文の節」）のとおり、書くことが無いと確かめた節には「なし」と書き、まだ調べていない節は置かない。

| 節 | 書くこと |
|---|---|
| `## 効果` | その値が何に影響するか。影響する二次ステータスやゲームシステムの文書へリンクする |
| `## 計算式` | 値の求め方。式ごとに `###` を立てる。式に使う値の表（グレードの係数など）も `###` に置く |
| `## 計算例` | 具体的な入力と、式に当てはめた途中の値と結果。式ごとに `###` を立てる |
