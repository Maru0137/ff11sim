# 防御力

防御力は、[二次ステータス](secondary_status.md)の 1 つで、被ダメージに関係する値である [1]。

_インスタンス元_: 二次ステータス

## 効果

物理攻撃のダメージの計算では、攻撃する側の攻撃力を防御する側の防御力で割った値（攻防比）を使う [2]。
攻防比から、固定ダメージに掛ける倍率とその分布が決まる。この倍率を求める関数は「攻防関数」と呼ばれる [2]。
防御力は攻防比の分母なので、防御力が上がると攻防比は下がる。攻撃力の求め方は [物理攻撃力](physical_attack.md) にある。

## 計算式

### 防御力

```
防御力 = int(VIT × 1.5) + レベル + α + 装備の防 + 防御ボーナス
```

`int()` は小数点以下の切り捨て [1]。

| 項 | 内容 |
|---|---|
| VIT | キャラクターの VIT（[基本ステータス](base_stats.md)） |
| レベル | メインジョブのレベル（1〜99） |
| α | レベルによる補正（「α（レベルによる補正）」節） |
| 装備の防 | 装備の防（DEF）の合計 |
| 防御ボーナス | ジョブ特性・ギフト・ジョブポイントのカテゴリによる固定値のボーナス（「防御ボーナス」節） |

### α（レベルによる補正）

α はレベル 1 で 8 から始まり、レベル 99 で 23 になる [1]。

| レベル | α |
|---|---|
| 1〜50 | 8 |
| 51〜59 | 8 + (レベル − 50) |
| 60〜90 | 18 |
| 91〜99 | 18 + int((レベル − 89) ÷ 2) |

具体値:

| レベル | α |
|---|---|
| 50 | 8 |
| 55 | 13 |
| 59 | 17 |
| 60〜90 | 18 |
| 91 | 19 |
| 95 | 21 |
| 99 | 23 |

### 防御ボーナス

```
防御ボーナス = ジョブ特性「物理防御力アップ」（メインジョブとサポートジョブの大きい方）
             + ギフト「物理防御力アップ」
             + ジョブポイントのカテゴリの防御力
```

#### ジョブ特性「物理防御力アップ」

メインジョブとサポートジョブで習得したランクのうち、大きい方の値を使う。2 つを足さない。

ランクごとの累積値は次のとおり [3]。

| ランク | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 値 | 10 | 22 | 35 | 48 | 60 | 72 |

習得するジョブとレベルは次のとおり [3]。青魔道士は青魔法のセットで得る追加特性として持つ [3]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| ナイト | 10, 30, 50, 70, 76, 91 | 6（+72） |
| 戦士 | 10, 45, 86 | 3（+35） |

#### ギフト「物理防御力アップ」

メインジョブの累計ジョブポイントに応じて段階が解放され、解放した段階の値の総和を足す。ギフトの枠ごとに 4 段階ある。
戦士の値は段階ごとに +10 / +15 / +20 / +25 で、全段階を解放すると +70 になる [4]。

段階を解放する累計ジョブポイントは、全ジョブで共通で、ギフトの枠の位置によって違う。

| 枠の位置 | 解放する累計ジョブポイント |
|---|---|
| 0 | 5, 180, 605, 1280 |
| 1 | 10, 210, 660, 1360 |
| 2 | 20, 245, 720, 1445 |
| 3 | 30, 280, 780, 1530 |
| 4 | 45, 320, 845, 1620 |
| 5 | 60, 360, 910, 1710 |

#### ジョブポイントのカテゴリの防御力

一部のジョブの一部のカテゴリだけが、防御力に直接寄与する。戦士のカテゴリは防御力に寄与しない（0）。

### 計算の順序

上の式で基本の値を求めた後、ステータスの変化などを次の順に計算する [1]。

1. 固定値を足し引きする。ジョブ特性「物理防御力アップ」・ギフト・プロテスなど。
2. 食事以外の、割合で効く要素の合計を掛ける。割合の合計が −100% を超えると、防御力は 1 になる。
3. 割合で効く食事の効果を掛ける。食事ごとに固定値の上限があり、上限を超えた分は切り捨てる。

計算の順序の 1・2 で足し引きされるものには、次がある。どれが固定値でどれが割合かは、[1] の一覧からは分からない。

#### 防御力を上げるもの

次のものが防御力を上げる [1]。

- 白魔法「プロテス」系
- 呪歌「重装騎兵のミンネ」
- ファントムロール「ガランツロール」
- 風水魔法「インデバリア」「ジオバリア」
- ステータス変化「防御力アップ」
- ステータス変化「VITアップ」（VIT を上げることで間接に上げる）
- 青魔法「マイティガード」
- 契約の履行：験術「ルビーの輝き」
- 神獣の加護「タイタンの加護」
- 食事（主に甲殻類を使う魚介料理）
- ジョブアビリティ「ディフェンダー」

#### 自分の防御力を下げるもの

次のジョブアビリティを使うと、自分の防御力が下がる [1]。

- かまえる
- [バーサク](../job_abilities/berserk.md)
- ラストリゾート

#### 相手の防御力を下げるもの

次のものが相手の防御力を下げる [1]。

- 白魔法「ディア」系
- 風水魔法「インデフレイル」「ジオフレイル」
- ステータス異常「防御力ダウン」
- ステータス異常「VITダウン」「チョーク」（VIT を下げることで間接に下げる）

## 計算例

戦士99・マスターレベル50・VIT 200・装備の防 500・ジョブポイントをすべて習得したとき:

| 項 | 値 |
|---|---|
| int(VIT × 1.5) | int(200 × 1.5) = 300 |
| レベル | 99 |
| α | 23（レベル 91〜99 の区分） |
| 装備の防 | 500 |
| 防御ボーナス | 35（戦士のジョブ特性ランク 3、レベル 86）+ 70（ギフト、2100 JP で全解放）+ 0（ジョブポイントのカテゴリ）= 105 |
| **防御力** | **300 + 99 + 23 + 500 + 105 = 1027** |


## 歴史

- **2013 年 3 月 27 日のバージョンアップ**: 攻防比が調整された。敵側の攻防比の上限が 2.0 から 4.0 に上がり、PC 側の防御力が低いと、以前より被ダメージが大きくなった [1]。
- **2016 年 8 月 3 日のバージョンアップ**: VIT の項が VIT × 0.5 から VIT × 1.5 に上がった。対象は PC 側（フェイス・フェロー・呼び出しペットなどを含む）だけで、敵や「あやつる」で使うペットは対象外 [1]。

## 未確認の事項

- 戦士のギフト「物理防御力アップ」の 3・4 段階目を解放する累計ジョブポイントが食い違っている。「ギフト「物理防御力アップ」」節の表（ff11sim のデータと同じ値）は 605 / 1280 だが、[4] は 550 / 1200 としている。[1] の表は戦士などの行を累積で +8 / +20 / +36 / +56 と読めたが、[4] の値（総和 +70）と食い違う。[1] の表は WebFetch で読み違えた可能性がある。なお、[ギフト（黒魔道士）/FF11用語辞典](https://wiki.ffo.jp/html/37179.html) の「魔法防御力アップ」（同じ枠の位置 0）は 5 / 180 / 605 / 1280 で、ff11sim のデータと一致する。
- ギフトの段階を解放する累計ジョブポイントの表（枠の位置ごと）は、戦士のギフトの 6 種類と [4] で照合した。枠の位置 0 の 3・4 段階目だけが食い違う（上の項目）。戦士のジョブポイントのカテゴリが防御力に寄与しないことの出典は無い。
- メインジョブとサポートジョブで習得したジョブ特性のランクの大きい方を使い、2 つを足さないことの出典は無い。
- [1] はマスターレベルに触れていない。マスターレベルが α に影響するかは分かっていない。
- 攻防比から固定ダメージに掛ける倍率（攻防関数）の形は調べていない。
- 防御力の上限は調べていない。
- 「計算の順序」の一覧の各項目が、固定値と割合のどちらで効くかは調べていない。
- 計算例は上の式に当てはめた値で、ゲーム内の表示とは照合していない。
