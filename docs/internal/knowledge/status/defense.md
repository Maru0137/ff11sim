# 防御力 (Defense)

キャラクターの防御力の計算式を記録する。

## 計算式

```
防御力 = int(VIT × 1.5) + レベル + α + 装備の防 + 防御ボーナス
```

| 項 | 内容 |
|---|---|
| VIT | キャラクターの VIT（種族・メインジョブ・サポートジョブ・マスターレベル・メリットポイント・装備の和） |
| レベル | メインジョブのレベル（1〜99） |
| α | レベルによる補正（次節） |
| 装備の防 | 装備の防（DEF）の合計 |
| 防御ボーナス | ジョブ特性・ギフト・ジョブポイントのカテゴリによるボーナス |

`int()` は小数点以下の切り捨て [1]。

## α（レベルによる補正）

| レベル | α |
|---|---|
| 1〜50 | 8 |
| 51〜59 | 8 + (レベル − 50) |
| 60〜90 | 18 |
| 91〜99 | 18 + int((レベル − 89) ÷ 2) |

具体値 [1]:

| レベル | α |
|---|---|
| 50 | 8 |
| 55 | 13 |
| 59 | 17 |
| 60〜90 | 18 |
| 91 | 19 |
| 95 | 21 |
| 99 | 23 |

## 防御ボーナス

```
防御ボーナス = ジョブ特性「防御力アップ」（メインジョブとサポートジョブの大きい方）
             + ギフトの防御力
             + ジョブポイントのカテゴリの防御力
```

### ジョブ特性「防御力アップ」

メインジョブとサポートジョブで習得したランクのうち、大きい方の値を使う。2 つを足さない [1]。

ランクごとの累積値は次のとおり [1]。

| ランク | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 値 | 10 | 22 | 35 | 48 | 60 | 72 |

習得するジョブとレベルは次のとおり [1]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| ナイト | 10, 30, 50, 70, 76, 91 | 6（+72） |
| 戦士 | 10, 45, 86 | 3（+35） |

### ギフトの防御力

メインジョブの累計ジョブポイントに応じて、段階ごとの値を足す。ギフトの枠ごとに 4 段階あり、4 段階すべてを解放すると累積値が決まる。戦士の値は [10, 15, 20, 25] で、全段階を解放すると +70 になる。

段階を解放する累計ジョブポイントは、全ジョブで共通で、ギフトの枠の位置によって違う。

| 枠の位置 | 解放する累計ジョブポイント |
|---|---|
| 0 | 5, 180, 605, 1280 |
| 1 | 10, 210, 660, 1360 |
| 2 | 20, 245, 720, 1445 |
| 3 | 30, 280, 780, 1530 |
| 4 | 45, 320, 845, 1620 |
| 5 | 60, 360, 910, 1710 |

### ジョブポイントのカテゴリの防御力

一部のジョブの一部のカテゴリだけが、防御力に直接寄与する。戦士のカテゴリは防御力に寄与しない（0）。

## 計算例

戦士99・マスターレベル50・VIT 200・装備の防 500・ジョブポイントをすべて習得したとき:

| 項 | 値 |
|---|---|
| int(VIT × 1.5) | int(200 × 1.5) = 300 |
| レベル | 99 |
| α | 23（レベル 91〜99 の区分） |
| 装備の防 | 500 |
| 防御ボーナス | 35（戦士のジョブ特性ランク 3、レベル 86）+ 70（ギフト、2100 JP で全解放）+ 0（ジョブポイントのカテゴリ）= 105 |
| **防御力** | **300 + 99 + 23 + 500 + 105 = 1027** |
