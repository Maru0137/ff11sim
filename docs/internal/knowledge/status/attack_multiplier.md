# 攻撃力の乗算枠

加算枠 (基本攻撃力・攻撃力+・歌) については [attack.md](attack.md) を参照。

## 攻撃力の計算構造

攻撃力は 3 段階で構成される。

```
攻撃力 = int(加算枠 × (256 + Σ乗算枠) / 256) + 計算後加算枠
```

| 段階 | 内容 | 参照 |
|---|---|---|
| 加算枠 | 基本攻撃力 (武器スキル + STR + 8)、攻撃力+ (ジョブ特性 / 装備 / ジョブポ / ギフト / イオニス)、歌 | [attack.md](attack.md) |
| 乗算枠 | ジョブ特性 / アビリティ / 支援魔法 / ファントムロール による割合上昇 | 本ドキュメント |
| 計算後加算枠 | 食事、応援 (チャチャルン) | 後述 |

## 256分率の原則

内部処理はすべて **256分率** で行われる。ゲーム内表記の 100分率は人間向けの近似値であり、
100分率のまま計算するとダメージがずれる。

### 表記揺れ

**同じ 100分率表記でも 256分率値が異なる場合がある。** 100分率表記は情報として不完全であり、
項目ごとに実測値を持つ必要がある。

| 例 | 100分率 | 256分率 | 実効値 |
|---|---|---|---|
| 青魔法 N.メディテイト | +20% | 52/256 | +20.31% |
| 青魔法 カルカリアンヴァーヴ | +20% | 51/256 | +19.92% |

### 丸め規則

丸め規則は項目ごとに一定でない。切り捨て (`floor(表記% × 256 / 100)`) に一致する項目が多いが、
四捨五入相当の項目も混在する。

- 切り捨て例: スマイト +20% → 51.2 → **51**
- 四捨五入例: N.メディテイト +20% → 51.2 → **52**

> 実装方針: 100分率から換算式で導出せず、項目ごとに実測された 256分率値をテーブルで保持する。

## 乗算枠同士の合成

**乗算枠同士は加算で合成される。** 個別に倍率を求めて最後に足しても結果は同じ。

```
倍率 = (256 + Σ 各項目の256分率値) / 256
```

例: スマイト rank5 (76) + バーサク rank6 (89) + ラストリゾート メリポ5振 (89)
→ `(256 + 76 + 89 + 89) / 256 = 510/256` (+99.2%)

## 乗算枠に含まれないもの

| 項目 | 扱い |
|---|---|
| 攻+N の実数値 (装備 / ギフト / ジョブ特性「物理攻撃力アップ」 / ジョブポ / イオニス) | 加算枠 |
| 歌 (メヌエット / 栄典の戴冠マーチ / 剛力・怪力) | 加算枠 |
| 食事 | **計算後加算枠**。乗算の影響を受けず、全ての計算終了後に加算 |
| 応援 (チャチャルン) | **計算後加算枠**。同上 |

> 食事・応援の STR 上昇分は STR 枠に加算されるため、そちらは乗算の影響を受ける。
> 乗算の影響を受けないのは「攻撃力」への直接加算分のみ。

## 実装

現状未対応。`rust/src/status.rs` の攻撃力算出は加算枠のみで、乗算枠は一切反映していない。

対応する場合の想定:

- 乗算枠の 256分率値テーブルを項目ごとに保持 (100分率からの換算はしない)
- 加算枠の算出後に `int(加算枠 × (256 + Σ乗算枠) / 256)` を適用
- 食事・応援の攻撃力加算はその後に加算
