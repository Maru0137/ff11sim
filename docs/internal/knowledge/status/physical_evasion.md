# 物理回避（回避）

物理回避は、[二次ステータス](secondary_status.md)の 1 つで、物理攻撃の回避率に関わる値である。ゲームでは「回避」と呼ぶ [1]。

_インスタンス元_: 二次ステータス
_排他_: 魔法回避

## 効果

物理回避は、物理攻撃を受けたときの回避率（攻撃をかわす確率）に関わる。近接攻撃と遠隔攻撃を問わず効く [1]。
物理命中（[物理命中](physical_accuracy.md)）は近接と遠隔で別の値だが、物理回避は 1 つの値で両方に効く。

装備で物理回避を上げるのは「回避+」である（[二次ステータス](secondary_status.md) の一覧）。

## 計算式

### 物理回避

```
物理回避 = int(AGI × 0.5) + 回避スキルの項 + 装備の回避 + 物理回避ボーナス
```

`int()` は小数点以下の切り捨て [1]。

| 項 | 内容 |
|---|---|
| AGI | キャラクターの AGI（[基本ステータス](base_stats.md)） |
| 回避スキルの項 | 回避スキルの有効スキル値から求める（「回避スキルの項」節） |
| 装備の回避 | 装備の「回避+」の合計 |
| 物理回避ボーナス | ジョブ特性・ギフト・ジョブポイントのカテゴリによるボーナス（「物理回避ボーナス」節） |

### 回避スキルの項

回避スキル 1 あたりの上がり方が、区分ごとに違う [1]。

| 回避スキルの有効スキル値 | 回避スキルの項 |
|---|---|
| 200 以下 | スキル値そのまま |
| 201〜400 | 200 + int((skill − 200) × 0.9) |
| 401 以上 | 380 + int((skill − 400) × 0.8) |

具体値:

| skill | 回避スキルの項 |
|---|---|
| 100 | 100 |
| 200 | 200 |
| 300 | 290 |
| 400 | 380 |
| 500 | 460 |
| 600 | 540 |

近接物理命中の武器スキルの項（[近接物理命中](melee_accuracy.md)）は 601 以上で係数が 0.9 に戻るが、回避スキルの項は 401 以上がずっと 0.8 である [1]。

### 回避スキルの有効スキル値

```
回避スキルの有効スキル値 = min(キャラクターの回避スキル値, スキル上限)
                         + メリットポイントの分
                         + 全スロット共通のスキルボーナス
                         + ギフトのスキルボーナス
```

| 項 | 内容 |
|---|---|
| スキル上限 | メインジョブ（レベルとマスターレベル）とサポートジョブ（有効レベル。マスターレベルは足さない）の回避スキルの上限の大きい方。求め方は [スキル](skill.md) |
| メリットポイントの分 | 回避スキルのメリットポイントのランク × 2（ランク 0〜8、最大 +16）。スキル上限で抑えた後に足す [4] |
| 全スロット共通のスキルボーナス | 装備の回避スキル+ の合計 |
| ギフトのスキルボーナス | ギフトの回避スキルのボーナス（無いジョブは 0） |

メインジョブとサポートジョブのどちらも回避スキルを持たない（スキル上限が 0 の）ときも、メリットポイントの分・全スロット共通のスキルボーナス・ギフトのスキルボーナスは足す [4]。

### 物理回避ボーナス

```
物理回避ボーナス = ジョブ特性「物理回避率アップ」（メインジョブとサポートジョブの大きい方）
                 + ギフト「物理回避アップ」
                 + ジョブポイントのカテゴリの回避
```

#### ジョブ特性「物理回避率アップ」

物理回避率にボーナスを得るジョブ特性である [2]。ランクごとの値は次のとおり [2]。

| ランク | 特性値 | 累積値 |
|---|---|---|
| 1 | +10 | +10 |
| 2 | +12 | +22 |
| 3 | +13 | +35 |
| 4 | +13 | +48 |
| 5 | +12 | +60 |
| 6 | +12 | +72 |

習得するジョブとレベルは次のとおり [2]。青魔道士は、青魔法のセットで得る追加特性として持つ [2]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| シーフ | 10, 30, 50, 70, 76, 88 | 6（+72） |
| 踊り子 | 15, 45, 75, 86 | 4（+48） |
| からくり士 | 20, 40, 60, 76 | 4（+48） |
| 青魔道士（追加特性。最短のレベル） | 69, 99, 99 | 3 |

#### ギフト「物理回避アップ」

メインジョブの累計ジョブポイントに応じて段階が解放され、解放した段階の値の総和を足す。戦士の値は次のとおり [3]。

| 段階 | 解放する累計ジョブポイント | 値 | 総和 |
|---|---|---|---|
| 1 | 20 | +5 | +5 |
| 2 | 245 | +8 | +13 |
| 3 | 720 | +10 | +23 |
| 4 | 1445 | +13 | +36 |

#### ジョブポイントのカテゴリの回避

一部のジョブの一部のカテゴリだけが、回避に直接寄与する。

## 計算例

AGI 200、回避スキルの有効スキル値 450、装備の回避 100 の戦士で、ギフトをすべて解放したとき（ジョブ特性は無い）:

- int(AGI × 0.5) = int(200 × 0.5) = 100
- 回避スキルの項 = 380 + int((450 − 400) × 0.8) = 380 + 40 = 420
- 物理回避ボーナス = 0（ジョブ特性）+ 36（ギフト）+ 0（ジョブポイントのカテゴリ）= 36

```
物理回避 = 100 + 420 + 100 + 36 = 656
```

## 未確認の事項

- [1][2][3] は WebFetch で要約して読んだもので、原文を目で確かめていない。
- [2] の習得レベルの表は列見出しが崩れていたので、位置から列を推定した。シーフ・踊り子・からくり士の値は書き直し前のこの文書と一致した。
- メリットポイントの分をスキル上限で抑えた後に足すこと、スキル上限が 0 のスキルにも足すことは [4] で決めた扱いで、ゲームの一次情報では確かめていない。
- ギフト「物理回避アップ」は戦士の値だけを確かめた。
- 計算例はこの文書の式に当てはめた値で、ゲーム内の表示とは照合していない。
- メインジョブとサポートジョブのランクの大きい方を使うことの出典は無い。
