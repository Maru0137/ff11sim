# 近接物理命中（命中）

近接物理命中は、[物理命中](physical_accuracy.md)の 1 つで、近接攻撃が当たるかどうかに関わる値である。ゲームでは一般に「命中」と呼ぶ [1]。

_インスタンス元_: 物理命中
_排他_: 遠隔物理命中

## 効果

近接物理命中は、近接攻撃の命中率（攻撃が当たる確率）を決める値の 1 つである [1]。命中率は、近接物理命中と相手の回避から決まる。

## 計算式

### 近接物理命中

```
近接物理命中 = int(DEX × 0.75) + 武器スキルの項 + 装備の命中 + 物理命中ボーナス
```

`int()` は小数点以下の切り捨て [1]。

| 項 | 内容 |
|---|---|
| DEX | キャラクターの DEX（[基本ステータス](../base_status/base_stats.md)） |
| 武器スキルの項 | その武器の武器のスキル値から求める（「武器スキルの項」節） |
| 装備の命中 | 装備の「命中+」の合計 |
| 物理命中ボーナス | ジョブ特性・ギフト・ジョブポイントのカテゴリによるボーナス。遠隔物理命中と共通（[物理命中](physical_accuracy.md) の「共通の規則」） |

メインの武器とサブの武器では、式は同じで、武器のスキル値がそれぞれの武器のものになる。

### 武器スキルの項

武器のスキル値 1 あたりの上がり方が、区分ごとに違う [1]。

| 武器のスキル値 | 武器スキルの項 |
|---|---|
| 0 以下 | 0 |
| 1〜200 | スキル値そのまま |
| 201〜400 | 200 + int((skill − 200) × 0.9) |
| 401〜600 | 380 + int((skill − 400) × 0.8) |
| 601 以上 | 540 + int((skill − 600) × 0.9) |

具体値:

| skill | 武器スキルの項 |
|---|---|
| 100 | 100 |
| 200 | 200 |
| 300 | 290 |
| 400 | 380 |
| 500 | 460 |
| 600 | 540 |
| 700 | 630 |
| 800 | 720 |

## 計算例

ヒューム 戦士99 / 侍59、マスターレベル50、ラフリア装備セットのメインの近接物理命中:

- DEX（装備込み）= 156 + 179 = 335
- 両手斧の武器のスキル値 = 788
- 武器スキルの項 = 540 + int((788 − 600) × 0.9) = 540 + int(169.2) = 709
- 装備の命中 = 448
- 物理命中ボーナス = 0（ジョブ特性）+ 36（ギフト）+ 0（ジョブポイントのカテゴリ）= 36

```
近接物理命中 = int(335 × 0.75) + 709 + 448 + 36
            = 251 + 709 + 448 + 36
            = 1444
```

## 歴史

- **2007 年 8 月 28 日より前**: DEX の係数は 0.5 だった。このバージョンアップで、両手武器だけ 0.75 になった [1]。
- **2013 年 7 月 9 日のバージョンアップ**: 格闘と片手武器の DEX の係数も 0.75 になった [1]。

## 未確認の事項

- [1] は WebFetch で要約して読んだもので、原文を目で確かめていない。
- 命中率が近接物理命中と相手の回避から決まることは、[1] の要約からは確かめていない。
- 計算例の入力は ff11sim で組んだ装備セットの値で、ゲーム内の表示とは照合していない。
