# 命中 (Accuracy)

キャラクターのメインの命中と遠隔の命中（飛命）の計算式を記録する。2 つは能力値・武器スキルの項の式・ボーナスの構成が違うので、別々に求める。

## メインの命中

```
命中 = int(DEX × 0.75) + 武器スキルの項（近接） + 装備の命中 + 命中ボーナス
```

`int()` は小数点以下の切り捨て [1]。

## 遠隔の命中（飛命）

```
飛命 = int(AGI × 0.75) + 武器スキルの項（遠隔） + 装備の飛命 + 命中ボーナス + 飛命専用ボーナス
```

能力値の係数は、メインの命中（DEX）と飛命（AGI）のどちらも 0.75 である。武器スキルの項は、近接と遠隔で式が違う [1][2]。

## 武器スキルの項

### 近接

武器のスキル値から、区分ごとの線形の式で求める [1]。

| 武器のスキル値 | 武器スキルの項（近接） |
|---|---|
| 0 以下 | 0 |
| 1〜200 | スキル値そのまま |
| 201〜400 | 200 + int((skill − 200) × 0.9) |
| 401〜600 | 380 + int((skill − 400) × 0.8) |
| 601 以上 | 540 + int((skill − 600) × 0.9) |

### 遠隔

近接は 200・400・600 で係数が変わるが、遠隔は 200 でだけ変わる [2]。

| 武器のスキル値 | 武器スキルの項（遠隔） |
|---|---|
| 0 以下 | 0 |
| 1〜200 | スキル値そのまま |
| 201 以上 | 200 + int((skill − 200) × 0.9) |

近接と遠隔の具体値:

| skill | 近接 | 遠隔 |
|---|---|---|
| 100 | 100 | 100 |
| 200 | 200 | 200 |
| 300 | 290 | 290 |
| 400 | 380 | 380 |
| 500 | 460 | 470 |
| 600 | 540 | 560 |
| 700 | 630 | 650 |
| 733 | 659 | 679 |
| 800 | 720 | 740 |

## 命中ボーナス

メインの命中と飛命の両方に足す。

```
命中ボーナス = ジョブ特性「命中率アップ」（メインジョブとサポートジョブの大きい方）
             + ギフトの命中
             + ジョブポイントのカテゴリの命中
```

### ジョブ特性「命中率アップ」

ランクごとの累積値は次のとおり [1]。

| ランク | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 値 | 10 | 22 | 35 | 48 | 60 | 72 |

習得するジョブとレベルは次のとおり [1]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| 狩人 | 10, 30, 50, 70, 86, 96 | 6（+72） |
| 竜騎士 | 30, 60, 76 | 3（+35） |
| 踊り子 | 30, 60, 76 | 3（+35） |
| 魔導剣士 | 50, 70, 90 | 3（+35） |

### ギフトの命中

メインジョブの累計ジョブポイントで解放される段階の値を累積する。戦士で全段階を解放したとき（2100 JP）は [5, 8, 10, 13] の累積で +36 になる。

### ジョブポイントのカテゴリの命中

一部のジョブの一部のカテゴリだけが、命中に直接寄与する。戦士のカテゴリは命中に寄与しない（0）。

## 飛命専用ボーナス

飛命にだけ足し、メインの命中には足さない。

```
飛命専用ボーナス = ギフトの飛命 + ジョブポイントのカテゴリの飛命
```

コルセアのジョブポイントのカテゴリ「遠隔命中アップ」は、ランクごとに飛命を +1 する。最大ランク 20 で +20 になる [3]。

## 計算例

### ヒューム 戦士99 / 侍59 マスターレベル50、ラフリア装備セット（メインの命中）

入力:

- DEX（装備込み）= 156 + 179 = 335
- 両手斧の武器のスキル値 = 788
- 武器スキルの項（近接）= 540 + int((788 − 600) × 0.9) = 540 + int(169.2) = 709
- 装備の命中 = 448
- 命中ボーナス = 0（ジョブ特性）+ 36（ギフト）+ 0（ジョブポイントのカテゴリ）= 36

```
命中 = int(335 × 0.75) + 709 + 448 + 36
     = int(251.25) + 709 + 448 + 36
     = 251 + 709 + 448 + 36
     = 1444
```

### ヒューム コルセア99 / 侍59 マスターレベル50、遠隔WS 装備セット（飛命）

入力:

- AGI（装備込み）= 378
- 射撃の武器のスキル値 = 733（スキル上限 448 + メリットポイント 16 + 装備 269）
- 武器スキルの項（遠隔）= 200 + int((733 − 200) × 0.9) = 200 + 479 = 679
- 装備の飛命 = 460
- 命中ボーナス = 0（ジョブ特性）+ 36（ギフトの 4 番目の枠）+ 0（ジョブポイントのカテゴリ）= 36
- 飛命専用ボーナス = 0（ギフト）+ 20（ジョブポイントのカテゴリ「遠隔命中アップ」ランク 20）= 20

```
飛命 = int(378 × 0.75) + 679 + 460 + 36 + 20
     = int(283.5) + 679 + 460 + 36 + 20
     = 283 + 679 + 460 + 36 + 20
     = 1478
```

## ff11sim での扱い

- 計算の入力と内訳は仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md) で決めている。武器のスキル値の語はその「用語」節の定義に従う。求め方は [attack.md](attack.md) と [skill_cap.md](skill_cap.md)。
- ギフトの各ジョブの値は `rust/src/job_points.rs` の `JOB_GIFTS` に持つ。
- 装備の「ウェポンスキルの命中+」はウェポンスキルにだけ効くものとして扱い、命中に足さない。命中を拾う正規表現（`rust/src/equip_stats.rs` の `accuracy`）が `skill ` の後に続く `accuracy` を除いている。
- ゲームにはあるが計算していない項目は [tech-debt/status-knowledge-gaps.md](../../tech-debt/status-knowledge-gaps.md) にある。
