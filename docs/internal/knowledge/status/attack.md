# 攻撃力 (Attack)

キャラクターの攻撃力のうち、加算で求める部分（加算枠）の計算式を記録する。メイン・サブ・遠隔（飛攻）の 3 つを別々に求める。
加算枠に掛ける割合の上昇（乗算枠）は [attack_multiplier.md](attack_multiplier.md) にある。

## メインの攻撃力

```
メインの攻撃力 = STR の項 + 武器のスキル値 + 8 + 装備の攻 + 攻撃ボーナス
```

### STR の項

| メインの武器 | STR の項 |
|---|---|
| 格闘 | int(STR × 0.75) |
| 片手武器・両手武器 | STR |

`int()` は小数点以下の切り捨て [1]。

### 武器のスキル値

メインの武器のスキルについての武器のスキル値（そのスキルの有効スキル値に、メインスロットのスロット専用のスキルボーナスを足したもの）を使う [1][2]。

```
武器のスキル値 = min(キャラクターのスキル値, スキル上限)
              + メリットポイントの分
              + 全スロット共通のスキルボーナス
              + ギフトのスキルボーナス
              + メインスロットのスキルボーナス
```

| 項 | 内容 |
|---|---|
| スキル上限 | メインジョブ（レベルとマスターレベル）とサポートジョブ（有効レベル。マスターレベルは足さない）のスキル上限の大きい方。メリットポイントでは広がらない（[skill_cap.md](skill_cap.md)） |
| メリットポイントの分 | そのスキルのメリットポイントのランク × 2（ランク 0〜8、最大 +16）。スキル上限で抑えた後に足す |
| 全スロット共通のスキルボーナス | スロット専用でないすべてのスキル+。防具・盾・グリップ・楽器・風水鈴・投てき武器でない矢弾のもの、アイテムレベル装備でない武器のもの、アイテムレベル装備の武器が持つ自分以外のスキルのもの |
| ギフトのスキルボーナス | ギフトによるそのスキルのボーナス。武器のスキルのギフトは今のところ無いので 0 |
| メインスロットのスキルボーナス | メインスロットに着けた、アイテムレベル装備の武器が持つ、自分の武器のスキルのスキル+ |

矢弾スロットの投てき武器（アイテムレベル装備）が持つ投てきスキル+ は、レンジスロットの武器のスキル値にだけ足す。メインの武器のスキル値には入らない [2]。

### 攻撃ボーナス

```
攻撃ボーナス = ジョブ特性「攻撃力アップ」（メインジョブとサポートジョブの大きい方）
             + ギフトの攻撃力
             + ジョブポイントのカテゴリの攻撃力
```

#### ジョブ特性「攻撃力アップ」

ランクごとの累積値は次のとおり [1]。

| ランク | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 値 | 10 | 22 | 35 | 48 | 60 | 72 | 84 | 96 |

習得するジョブとレベルは次のとおり [1]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| 暗黒騎士 | 10, 30, 50, 70, 76, 83, 91, 99 | 8（+96） |
| 戦士 | 30, 65, 91 | 3（+35） |
| 竜騎士 | 10, 91 | 2（+22） |

#### ギフトの攻撃力

メインジョブの累計ジョブポイントで解放される段階の値を累積する。戦士で全段階を解放したとき（2100 JP）は [10, 15, 20, 25] の累積で +70 になる。

#### ジョブポイントのカテゴリの攻撃力

一部のジョブの一部のカテゴリだけが、攻撃力に直接寄与する。戦士のカテゴリは攻撃力に寄与しない（0）。

## サブの攻撃力

```
サブの攻撃力 = サブの STR の項 + サブの武器のスキル値 + 8 + 装備の攻 + 攻撃ボーナス
```

### サブの STR の項

| サブの武器 | STR の項 |
|---|---|
| 格闘 | int(STR × 0.75) |
| 片手武器 | int(STR × 0.5) |

サブの格闘の係数は、メインの格闘と同じ 0.75 である。両手武器はサブスロットに着けられないので、表に無い [1]。

### サブの武器のスキル値

```
武器のスキル値 = min(キャラクターのスキル値, スキル上限) + メリットポイントの分 + 全スロット共通のスキルボーナス
              + ギフトのスキルボーナス + サブスロットのスキルボーナス
```

攻撃ボーナスはメインと同じである。

## 遠隔の攻撃力（飛攻）

```
飛攻 = STR + レンジの武器のスキル値 + 8 + 装備の飛攻 + 攻撃ボーナス
```

```
武器のスキル値 = min(キャラクターのスキル値, スキル上限) + メリットポイントの分 + 全スロット共通のスキルボーナス
              + ギフトのスキルボーナス + レンジスロットのスキルボーナス
```

メイン・サブ・遠隔で、攻撃ボーナスの構成は同じである。3 つの違いは STR の項の係数と、装備の値とスロット専用のスキルボーナスの足し先である [1]。

## 計算例

ヒューム 戦士99 / 侍59 マスターレベル50、ラフリア装備セットのメインの攻撃力:

入力:

- STR（装備込み）= 161 + 247 = 408
- 両手斧の武器のスキル値 = 490 + 277（メインスロットのラフリア）+ 21（全スロット共通、BI ロリカ）= 788。
  490 は min(キャラクターのスキル値, スキル上限 424 + マスターレベル 50 = 474) + メリットポイント 16 で、キャラクターのスキル値が 474 以上のときの値。
- 装備の攻 = 448
- 攻撃ボーナス = 35（戦士のジョブ特性ランク 3）+ 70（ギフト、2100 JP）+ 0（ジョブポイントのカテゴリ）= 105

```
メインの攻撃力 = 408 + 788 + 8 + 448 + 105
              = 1757
```

## ff11sim での扱い

- 計算の入力と内訳、スロット専用のスキルボーナスと全スロット共通のスキルボーナスの振り分けは、仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md) の「用語」節と AC23・AC26 で決めている。
- ギフトの各ジョブの値は `rust/src/job_points.rs` の `JOB_GIFTS` に持つ。
- 乗算枠は計算していない（[attack_multiplier.md](attack_multiplier.md)）。
- 実装はスキルの規則とサブの格闘の係数がこの文書と食い違っている。食い違いとゲームにはあるが計算していない項目は [tech-debt/status-knowledge-gaps.md](../../tech-debt/status-knowledge-gaps.md) にある。
