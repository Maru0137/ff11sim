# 得TP

得TP は、自分や外部からの行動で得る TP のことで、特に自分の攻撃で得る TP を指す [1]。

_種別_: value

## 仕組み

TP を得る手段は 3 種類ある [1]。

| 種類 | 内容 [1] |
|---|---|
| 能動的な得TP | 自分の行動で得る。物理攻撃やウェポンスキルを 1 ダメージ以上当てる、マジックアキュメンを持つ者が暗黒魔法・精霊魔法でダメージを与える、TP を上げるアイテムやアビリティを使う、など |
| リゲインによる得TP | リゲインの装備や、リゲインの状態になるアイテム・アビリティ（黙想など）で得る |
| 受動的な得TP | 攻撃を受けたり、味方の支援を受けたりして得る。攻撃する側がモクシャを持っていると減る |

この文書の「計算式」は、能動的な得TP のうち、オートアタックと遠隔攻撃の 1 ヒットで得る TP の求め方である [1]。

## 計算式

### 得TP

```
得TP = int(隔による基本値 × (100 + ストアTP) ÷ 100)
```

`int()` は小数点以下の切り捨て [1][2]。

### 隔による基本値

基本値の下限は 40 である [1][2]。

| 隔 | 基本値 |
|---|---|
| 〜180 | 61 + int((隔 − 180) × 63 ÷ 360) |
| 181〜540 | 61 + int((隔 − 180) × 88 ÷ 360) |
| 541〜630 | 149 + int((隔 − 540) × 20 ÷ 360) |
| 631〜720 | 154 + int((隔 − 630) × 28 ÷ 360) |
| 721〜900 | 161 + int((隔 − 720) × 24 ÷ 360) |
| 901〜 | 173 + int((隔 − 900) × 28 ÷ 360) |

隔 180 以下の係数（63/360）は、181〜540 の係数（88/360）より小さい。そのため隔を 180 より短くしても、得TP はあまり落ちない。

### 使う隔

基本値に入れる隔は、武器の構成で変わる [1][2]。

| 構成 | 隔 |
|---|---|
| 片手武器・両手武器（サブスロットに武器なし） | メインの武器の隔 |
| 二刀流（サブスロットに隔を持つ武器） | int((メインの隔 + サブの隔) × (100 − 二刀流) ÷ 100 ÷ 2) |
| 格闘（メインが格闘武器、または素手） | int((480 + メインの武器の隔 − マーシャルアーツ) ÷ 2) |
| 遠隔（弓術・射撃・投てき） | レンジの武器の隔 + 矢弾の隔 |

- **二刀流と格闘の ÷ 2**: どちらも 1 回の攻撃ラウンドで 2 回判定するので、1 ヒットあたりの隔は攻撃間隔の半分になる。両手とも同じ値になり、メインとサブで得TP は変わらない。
- **格闘の 480**: 格闘の基本の隔。装備の説明文の `隔+N` は 480 に足す量である。
- **マーシャルアーツ**: 格闘の攻撃間隔の短縮量。ジョブ特性（モンク・からくり士）、ギフト「マーシャルアーツ効果アップ」、装備の「マーシャルアーツ+N」の合計。
- **二刀流**: 攻撃間隔の短縮率（%）。ジョブ特性（シーフ・忍者・踊り子）、ギフト「二刀流効果アップ」、装備の「二刀流+N」の合計。
- **遠隔**: 矢弾の隔は攻撃間隔には影響しないが、得TP の隔には足す。
- **ヘイスト**: 攻撃間隔を縮めるだけで、得TP には影響しない。

## 計算例

隔 480 の片手武器をメインに着け、サブスロットに武器が無く、ストアTP が 10 のとき:

```
隔による基本値 = 61 + int((480 − 180) × 88 ÷ 360) = 61 + int(73.33) = 134
得TP = int(134 × (100 + 10) ÷ 100) = int(147.4) = 147
```
