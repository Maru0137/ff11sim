# 遠隔物理攻撃力（飛攻）

遠隔物理攻撃力は、[物理攻撃力](physical_attack.md)の 1 つで、遠隔攻撃の攻撃力のことである。ゲームでは「飛攻」と呼ぶ [1]。

_インスタンス元_: 物理攻撃力
_排他_: 近接物理攻撃力

## 効果

遠隔攻撃の与ダメージに関わる。装備の「攻+」は遠隔攻撃には影響しない [2]。装備で遠隔物理攻撃力を上げるのは「飛攻+」である。
ジョブ特性とギフトの「物理攻撃力アップ」は、遠隔物理攻撃力にも効く（[物理攻撃力](physical_attack.md) の「物理攻撃力ボーナス」）。

## 計算式

### 遠隔物理攻撃力

```
遠隔物理攻撃力 = STR + 武器のスキル値 + 8 + 装備の飛攻 + 物理攻撃力ボーナス
```

式の形は、片手武器・両手武器をメインに着けたときの近接物理攻撃力と同じである [1]。

| 項 | 内容 |
|---|---|
| STR | 係数は 1（[近接物理攻撃力](melee_attack.md) のメインの片手武器・両手武器と同じ） |
| 武器のスキル値 | 遠隔攻撃に使う武器のスキルの武器のスキル値（[物理攻撃力](physical_attack.md) の「武器のスキル値」） |
| 装備の飛攻 | 装備の「飛攻+」の合計 |
| 物理攻撃力ボーナス | 近接物理攻撃力と共通（[物理攻撃力](physical_attack.md) の「物理攻撃力ボーナス」） |

この式は加算枠で、乗算枠と計算後加算枠の扱いは [物理攻撃力](physical_attack.md) の「計算の構造」にある。
