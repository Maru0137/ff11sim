# 日本語説明文の条件ラベル

装備の日本語説明文 (`items.json` の `description_ja`) には、コロン付きのラベルで
「その効果が誰に乗るか / いつ乗るか」を示す表記がある。

```
防21 ペット:命中+3 モクシャ+3
```

この例の `命中+3` と `モクシャ+3` はどちらもペットのもので、装備者本体には乗らない。

## 適用範囲はソースによって変わる

ラベルの効力はラベル以降に及ぶ。ラベルより前は本体の常時効果。

```
防5 CHR+5 ヘイスト+5% ペット:ヘイスト+5%
→ 本体: 防5 / CHR+5 / ヘイスト+5%、ペット: ヘイスト+5%
```

どこで効力が切れるかは、**そのテキストの改行が何を意味するか**で決まる。
装備の解釈に使う 3 ソース (docs/adr/0019) のうち、アイテム説明文だけ規則が違う。

| ソース | 改行の意味 | ラベルの適用範囲 |
| --- | --- | --- |
| `items.json` の `description_ja` | ゲーム内表示の折り返し | 次のラベルかテキスト末尾まで |
| `augments.json` のオグメント文 | 効果 1 件ごとの区切り | 行末まで |
| カスタム説明 (ユーザー入力) | ユーザーが行単位で書く | 行末まで |

### アイテム説明文: 折り返し行もラベル配下

ゲーム内の説明文は 1 続きのテキストで、改行は表示上の折り返しにすぎない。
そのためラベルの効力は続きの行にも及ぶ。

```
防1 サンドリア王国軍支配エリア:
インビジ効果アップ スニーク効果アップ    ← 支配エリア内でのみ発動 (近衛騎士リバリ)
移動速度+12%                             ← 同上
```

```
防139 ... ヘイスト+6%
オートマトン:MP+110 ケアル回復量+16%
ヘイスト+5% 被ダメージ-6%                ← オートマトンのもの (ＦＯチュリダル+4)
コンビネーション:命中+ 飛命+ 魔命+       ← ここでラベルが切り替わる
```

`コンビネーション:` は常時扱い (後述) だが、直前のラベルの区切りにはなる。

2026-08 時点のデータで、ラベル行の後に続きの行があるアイテムは 383 件。
そのすべてで続きの行はラベル配下であり、反例 (配下に `防n` / `Ｄn` / `隔n` のような
本体専用の表記が来るもの) は 0 件だった。

`description_ja` の改行はリテラルの `\n` (バックスラッシュ + n) で入っている。

### オグメント文: 行末まで

`augments.json` の改行は wiki の `<br>` 由来で、効果 1 件ごとの区切りとして入っている
(`scripts/scrape_augments.py`)。折り返しではないので、続きの行は本体の効果。

```
ペット:攻+15
攻+5                    ← 本体の効果 (ネオアニメーター 21430)
```

```
命中+30 魔命+30
ペット:命中+30 魔命+30
ストアTP+7              ← 本体の効果 (ジャストクラウン 24165 Rank30)
トリプルアタック+4%     ← 同上
```

## コロンは半角と全角の両方がある

ほとんどは半角 `:` だが、慈悲/慈愛/寵愛装束 (id 24180-24194) の Rank30 オグメントだけが
全角の `ペット：` で書かれている。上流の wiki の表記ゆれで、こちらで直すと再スクレイプで
戻るため、読む側で両方を受ける。

## ラベルの種類

2026-08 時点のデータで、コロン付きラベルは 227 種類 (うち配下に数値を含むものが 170 種類)。
出現数の多い順に:

| ラベル | 件数 | 種別 |
| --- | --- | --- |
| コンビネーション | 1301 | 条件 (セット装備数)。ただし常時扱いにする（後述） |
| 追加効果 | 546 | 条件 (発動時) |
| エンチャント | 423 | 条件 (発動時) |
| 潜在能力 | 383 | 条件 |
| アフターマス | 341 | 条件 (WS 後) |
| ペット / 召喚獣 / オートマトン / 飛竜 / 呼び出しペット | 計 816 | 対象がペット |
| ユニティランク | 217 | 条件 (ユニティ順位) |
| 右耳 | 68 | 条件 (装備スロット) |
| デュナミス〔Ｄ〕/ レイヴ / ビシージ / カンパニエ 等 | — | 条件 (エリア・コンテンツ) |
| 曜日 / 天候 / 日中 / 夜間 / 満月 等 | — | 条件 (時間・天候) |
| 対ヴァーミン / 対プラントイド 等 | — | 条件 (敵の種族) |
| メインウェポン / 素手 / 侍 / ナ 等 | — | 条件 (装備・ジョブ) |

数値を伴うラベルはすべて「本体以外が対象」か「常時発動ではない条件」のいずれかで、
装備者に常時乗るステータスをコロン付きで書く表記は無い。
本体の常時ステータスは `防21` `命中+9` のようにコロンなしで書かれる。

なお英語説明文では `DMG:+165 Delay:+240` のようにステータス自体をコロンで書くため、
同じ規則をそのまま適用できない。

## コンビネーションだけは常時扱い

`コンビネーション:` はセット装備数で発動するので厳密には条件付きだが、
本ツールは装備セットを組むためのものでセット効果は実際に発動していることが多い。
そのため条件ラベルとして扱わず、配下の値を常時のものとして読む
（[ADR 0019](../../adr/0019-japanese-as-single-interpretation-source.md)）。
`コンビネーション(召喚獣のみ):` のような対象限定の変種は例外にしない。

## 抽出側の扱い

`rust/src/equip_stats.rs` が窓口。

- `strip_conditional_labels(text, mode)` — 条件ラベルとその配下を落とす。適用範囲は
  `LabelScopeMode`（`Wrapped` = 次のラベル/末尾まで、`PerLine` = 行末まで）で指定し、
  `rust/src/equip.rs` の `Equip::texts_ja` がソースごとに上表の値を渡す。
  装備の解釈はステータス計算もユーザー定義プロパティもここを通るので、両者の規則が揃う。
  ラベル自身も落とすのは、残すと後段の正規化で `ペット:` が `Pet:` になり、
  英語向けのセグメント除去が次のコロンまで食う既知の癖
  （[tech-debt](../../tech-debt/equip-stats-js-quirks.md)）を誘発するため。
- `extract_stat_from_description` — 検索の説明文ステータスソート用に、同じ規則で
  ラベル配下を読み飛ばす（生テキストを渡すのはアイテム説明文だけなので `Wrapped` 固定）。
  こちらはラベル自身を範囲に含めないので、`DEF:77` から
  `DEF` を引く用法や、`ペット:命中` のようにラベル込みの指定も残る。

ラベル判定の条件は「非 ASCII 文字を含むこと」。`description_ja` が無い装備は
`description_en` で代替するため、英語の `DMG:+165 Delay:+240 STR+10` のような
`ステータス:値` 表記を条件ラベルと誤認しないようにしている。

英語説明文 (`description_en`) にも折り返しがあり、ラベル配下が複数行に分かれる点は
日本語と同じ。ただし英語側の除去は「次のコロンまで」で行数を見ておらず挙動が違う
（[tech-debt](../../tech-debt/equip-stats-js-quirks.md) の 1 番）。
英語経路は参照実装としてしか使わないので、そのままにしてある。
