# ステータスの書き方

`type: ステータス` のナレッジの本文の形を定める。基本ステータス（HP・MP と BP の 9 項目）と、二次ステータス（攻撃力・命中・防御力など、基本ステータス以外のステータス）を説明するときに使う。ナレッジは `status/` に置く。
frontmatter・冒頭の文・末尾の節・出典などの共通の規則は [README.md](README.md) にある。

見本: [基本ステータス](../knowledge/status/base_stats.md)、[防御力](../knowledge/status/defense.md)

## 形

```markdown
---
type: ステータス
title: "防御力"
description: "<冒頭の定義を短く言い直した 1 文>"
status: draft
---

# 防御力

<タイトル> は、（<上位概念>のうち、 / <上位概念>の 1 つで、）…である。

_種別_: … / _上位_: … / _インスタンス元_: …

## 効果

## 計算式

## 計算例

## 上限（二次ステータスだけ）

## 歴史（任意）

## 未確認の事項

## 出典
```

## 本文の節

次の `##` をこの順にすべて置く。`## 上限` は二次ステータスの文書にだけ置き、基本ステータスの文書には置かない。
共通の規則（[README.md](README.md) の「本文の節」）のとおり、書くことが無いと確かめた節には「なし」と書き、まだ調べていない節は置かない。

| 節 | 書くこと |
|---|---|
| `## 効果` | その値がゲームの中で何に影響するか（例: 防御力は攻防比の分母になる）。影響するステータスやゲームシステムの文書へリンクする |
| `## 計算式` | 値の求め方。式ごとに `###` を立てる。式の項（ボーナスなど）、式に使う値の表（グレードの係数など）、計算の順序も `###` に置く。値を増減させる魔法・アビリティ・食事などは、計算の順序のどこで効くかと一緒に書く |
| `## 計算例` | 具体的な入力と、式に当てはめた途中の値と結果。式ごとに `###` を立てる |
| `## 上限` | 二次ステータスの値や効果の上限（例: ヘイストの上限）。無ければ「なし」 |
