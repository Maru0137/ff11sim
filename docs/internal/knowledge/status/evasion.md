# 回避 (Evasion)

キャラクターの回避の計算式を記録する。

## 計算式

```
回避 = int(AGI × 0.5) + 回避スキルの項 + 装備の回避 + 回避ボーナス
```

`int()` は小数点以下の切り捨て。

## 回避スキルの項

回避スキルの有効スキル値（次節）から、区分ごとの線形の式で求める [1]。

| 回避スキルの有効スキル値 | 回避スキルの項 |
|---|---|
| 200 以下 | スキル値そのまま |
| 201〜400 | 200 + int((skill − 200) × 0.9) |
| 401 以上 | 380 + int((skill − 400) × 0.8) |

具体値:

| skill | 回避スキルの項 |
|---|---|
| 100 | 100 |
| 200 | 200 |
| 300 | 290 |
| 400 | 380 |
| 500 | 460 |
| 600 | 540 |

命中の武器スキルの項（[accuracy.md](accuracy.md)）は 601 以上で係数が 0.9 に戻るが、回避スキルの項は 401 以上がずっと 0.8 である [1]。

## 回避スキルの有効スキル値

```
回避スキルの有効スキル値 = min(キャラクターの回避スキル値, スキル上限)
                         + メリットポイントの分
                         + 全スロット共通のスキルボーナス
                         + ギフトのスキルボーナス
```

| 項 | 内容 |
|---|---|
| スキル上限 | メインジョブ（レベルとマスターレベル）とサポートジョブ（有効レベル。マスターレベルは足さない）の回避スキルの上限の大きい方。求め方は [skill_cap.md](skill_cap.md) |
| メリットポイントの分 | 回避スキルのメリットポイントのランク × 2（ランク 0〜8、最大 +16）。スキル上限で抑えた後に足す [2] |
| 全スロット共通のスキルボーナス | 装備の回避スキル+ の合計 |
| ギフトのスキルボーナス | ギフトの回避スキルのボーナス（無いジョブは 0） |

メインジョブとサポートジョブのどちらも回避スキルを持たない（スキル上限が 0 の）ときも、メリットポイントの分・全スロット共通のスキルボーナス・ギフトのスキルボーナスは足す [2]。

## 回避ボーナス

```
回避ボーナス = ジョブ特性「回避率アップ」（メインジョブとサポートジョブの大きい方）
             + ギフトの回避
             + ジョブポイントのカテゴリの回避
```

### ジョブ特性「回避率アップ」

ランクごとの累積値は次のとおり [1]。

| ランク | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 値 | 10 | 22 | 35 | 48 | 60 | 72 |

習得するジョブとレベルは次のとおり [1]。

| ジョブ | 習得レベル | 最大ランク |
|---|---|---|
| シーフ | 10, 30, 50, 70, 76, 88 | 6（+72） |
| 踊り子 | 15, 45, 75, 86 | 4（+48） |
| からくり士 | 20, 40, 60, 76 | 4（+48） |

### ギフトの回避

メインジョブの累計ジョブポイントで解放される段階の値を累積する。戦士で全段階を解放したとき（2100 JP）は [5, 8, 10, 13] の累積で +36 になる。

### ジョブポイントのカテゴリの回避

一部のジョブの一部のカテゴリだけが、回避に直接寄与する [1]。

## ff11sim での扱い

- 計算の入力と内訳は仕様書 [0007 ステータスの計算](../../specs/0007-status-calculation.md) で決めている。有効スキル値の語はその「用語」節の定義に従う。
- 回避スキルは武器のスキルではないので、メイン・サブ・レンジのどのスロットの装備の回避スキル+ も、全スロット共通のスキルボーナスとして足す（仕様書 0007 の「スロット専用のスキルボーナス」）。
- ギフトの各ジョブの値は `rust/src/job_points.rs` の `JOB_GIFTS` に持つ。
- 実装はメリットポイントの扱いが [2] で改める前の規則のままである。食い違いとゲームにはあるが計算していない項目は [tech-debt/status-knowledge-gaps.md](../../tech-debt/status-knowledge-gaps.md) にある。
